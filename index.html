Python in Practice

Part I: Rapid Review & Core OOP Foundations

Chapter 1: Setting Up Python & PyCharm

Fast review of Python 3 virtual environments, PyCharm IDE setup, package layout, and running scripts from the terminal.
Chapter 2: Type Hints, Object State & Defensive Contracts

Reviewing static type hints, value normalization, isinstance guards, and fail-fast boundary checks before heavy code begins.
Chapter 3: Class Architecture, Invariants & Object Lifecycle

Designing cohesive classes, __init__ vs. factory classmethods, object identity vs. equality, and state transitions.
Chapter 4: Dataclasses, Slots & Immutable Value Objects

Mastering @dataclass, __post_init__ invariant validation, frozen=True value models, slots=True, and memory layout.

Part II: Data Model, Properties & Descriptors

Chapter 5: Dunder Protocols, Operator Overloading & Custom Containers

Hooking into Python's data model with __repr__, ordering/equality dunders, arithmetic operators, and custom collection protocols.
Chapter 6: Properties, Validation & The Descriptor Protocol

Moving from single-class @property guards to reusable data and non-data descriptors (__get__, __set__, __set_name__).
Chapter 7: Context Manager Classes & Resource Lifecycles

Implementing stateful __enter__ and __exit__ objects, exception suppression rules, and transactional rollback managers.

Part III: Inheritance, Protocols & Metaprogramming

Chapter 8: Inheritance, MRO & Composition Over Inheritance

Navigating multiple inheritance and C3 Method Resolution Order (MRO) with super(), and refactoring rigid trees into composable objects.
Chapter 9: Abstract Base Classes & Structural Protocols

Comparing nominal ABC interfaces (abc.ABC) with structural typing.Protocol contracts and runtime-checkable duck typing.
Chapter 10: __init_subclass__, Class Decorators & Metaclasses

Automating class registration and validation with __init_subclass__ and class decorators, and knowing when metaclasses are warranted.

Part IV: Patterns, Persistence, Security & Production OOP

Chapter 11: Strategy, Factory, Observer & Command Patterns

Applying classic object-oriented patterns idiomatically in Python with callables, protocols, and decoupled event publishers.
Chapter 12: Exception Hierarchies & Resilient Service Objects

Modeling domain error hierarchies, exception chaining, retryable operation objects, and structured logging inside services.
Chapter 13: Configuration, Serialization & Boundary Adapters

Validating runtime configuration objects, preserving precision during JSON serialization, and translating external payloads through boundary adapters.
Chapter 14: Rate Limiters, Circuit Breakers & Resilient Gateways

Building token-bucket rate limiters, circuit breaker state machines, and resilient outbound gateways for downstream services.
Chapter 15: Thread-Safe Objects, Async Clients & Fakes in pytest

Synchronizing shared object state with locks, building async service classes, and testing with protocol-compliant fakes and pytest.
Chapter 16: Observability, Metrics & Audit Trails in OOP Systems

Instrumenting counters and scoped timers, recording immutable audit trails with correlation IDs, and exposing thread-safe telemetry snapshots.
