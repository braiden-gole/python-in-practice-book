Chapter 9: Abstract Base Classes & Structural Protocols

When composing objects or building pluggable components, you often care about what capabilities an object provides rather than its entire concrete class tree. Python supports both Abstract Base Classes (ABCs) for nominal inheritance contracts and typing.Protocol for structural ("duck typing") interfaces.

ABCs vs. structural protocols: An ABC requires subclasses to inherit explicitly and prevents instantiation until all @abstractmethod hooks are implemented. A Protocol checks whether an object satisfies the required method or attribute signatures structurally, even across unrelated classes.

Why both matter in real codebases: ABCs shine when a family of classes shares base helpers and explicit hierarchy guarantees, while Protocol shines when decoupling callers from concrete implementations or third-party types.

Interface Style Mechanism / Syntax Primary Strength Defensive Pitfall to Avoid
Abstract Base Class class Base(ABC): + @abstractmethod Blocks incomplete subclasses at instantiation time and shares base code Over-constraining unrelated classes into a forced inheritance tree
Structural Protocol class Exporter(Protocol): Decouples callers structurally without forcing base-class inheritance Assuming isinstance(..., Protocol) checks method bodies or runtime types at runtime
Runtime Checkable @runtime_checkable Allows isinstance() checks for presence of required attributes/methods Relying solely on isinstance() when argument/return types also matter
Shared Guard Helpers Concrete helper methods on an ABC Centralizes input validation before calling abstract implementation hooks Duplicating validation rules across every concrete implementation
Core Principles of ABCs & Structural Protocols
  • Use @abstractmethod to enforce required contracts: Any concrete subclass that omits an abstract method raises TypeError when instantiated.
  • Keep method signatures and invariants aligned: Implementations must honor the expected parameter types, return values, and domain invariants of the interface.
  • Use Protocol to invert dependencies cleanly: High-level services can depend on a narrow Protocol rather than concrete classes, making testing and extension straightforward.
  • Validate runtime inputs defensively: Type checkers catch mismatches statically, while explicit runtime checks protect boundaries against dynamic or untyped callers.

9.1 Abstract Base Classes with Shared Validation

An ABC can pair shared validation logic in a concrete method with a required @abstractmethod hook that every subclass must implement.

from abc import ABC, abstractmethod
from decimal import Decimal, InvalidOperation

class TaxRule(ABC):
    """Abstract base class defining a validated tax calculation contract."""

    @staticmethod
    def _validate_subtotal(subtotal: object) -> Decimal:
        """Validate and normalize a non-negative finite Decimal subtotal."""
        # Reject booleans explicitly because bool subclasses int in Python.
        if isinstance(subtotal, bool):
            raise TypeError("Subtotal cannot be a boolean.")

        # Convert Decimal or string/numeric inputs into a Decimal safely.
        try:
            parsed_subtotal: Decimal = (
                subtotal
                if isinstance(subtotal, Decimal)
                else Decimal(str(subtotal).strip())
            )
        except (InvalidOperation, TypeError) as parse_error:
            raise ValueError(f"Invalid subtotal amount: {subtotal}.") from parse_error

        # Reject NaN, Infinity, or negative subtotals.
        if not parsed_subtotal.is_finite() or parsed_subtotal < Decimal("0.00"):
            raise ValueError("Subtotal must be a finite non-negative Decimal.")

        # Return validated Decimal subtotal.
        return parsed_subtotal

    def compute_tax(self, subtotal: object) -> Decimal:
        """Validate subtotal first, then delegate tax math to the subclass rule."""
        # Enforce shared subtotal validation before invoking concrete tax logic.
        validated_subtotal: Decimal = self._validate_subtotal(subtotal)

        # Delegate tax math to the subclass implementation.
        return self._calculate_tax_amount(validated_subtotal)

    @abstractmethod
    def _calculate_tax_amount(self, subtotal: Decimal) -> Decimal:
        """Calculate tax for a validated non-negative Decimal subtotal."""
        # Subclasses must implement this method to be instantiable.
        raise NotImplementedError

class FlatRateTaxRule(TaxRule):
    """Concrete tax rule applying a fixed percentage rate to a validated subtotal."""

    def __init__(self, tax_rate: Decimal) -> None:
        """Initialize and validate a non-negative finite tax rate."""
        # Reject booleans and non-Decimal rates defensively.
        if isinstance(tax_rate, bool) or not isinstance(tax_rate, Decimal):
            raise TypeError("tax_rate must be a Decimal.")

        # Reject NaN, Infinity, or negative tax rates.
        if not tax_rate.is_finite() or tax_rate < Decimal("0.00"):
            raise ValueError("tax_rate must be a finite non-negative Decimal.")

        # Store validated tax rate on the instance.
        self._tax_rate: Decimal = tax_rate

    def _calculate_tax_amount(self, validated_subtotal: Decimal) -> Decimal:
        """Compute tax by multiplying validated subtotal by the tax rate."""
        # Multiply validated subtotal by the instance tax rate.
        return validated_subtotal * self._tax_rate

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Compute tax on a validated subtotal using a concrete TaxRule subclass.
    ontario_hst_rule: FlatRateTaxRule = FlatRateTaxRule(Decimal("0.13"))
    tax_due: Decimal = ontario_hst_rule.compute_tax(Decimal("120.00"))

    print("Tax due:", tax_due)

9.2 Structural Protocols with typing.Protocol

A Protocol specifies the methods or attributes a collaborator must provide without requiring those classes to inherit from a shared base class.

from typing import Protocol, runtime_checkable

@runtime_checkable
class SummaryFormatter(Protocol):
    """Structural protocol for objects capable of formatting a record summary."""

    def format_summary(self, record_code: str, item_total: int) -> str:
        """Return a formatted summary string for a record code and item count."""
        ...

class PlainTextSummaryFormatter:
    """Standalone formatter matching SummaryFormatter structurally without subclassing."""

    def format_summary(self, record_code: str, item_total: int) -> str:
        """Format a compact single-line summary after validating inputs."""
        # Reject non-string record codes defensively.
        if not isinstance(record_code, str):
            raise TypeError("record_code must be a string.")

        # Normalize and reject blank record codes.
        cleaned_code: str = record_code.strip().upper()
        if not cleaned_code:
            raise ValueError("record_code cannot be blank.")

        # Reject booleans explicitly because bool subclasses int in Python.
        if isinstance(item_total, bool) or not isinstance(item_total, int):
            raise TypeError("item_total must be a non-boolean integer.")

        # Reject negative item totals.
        if item_total < 0:
            raise ValueError("item_total cannot be negative.")

        # Return formatted summary text.
        return f"{cleaned_code}: {item_total} items"

class ShipmentReporter:
    """Service depending structurally on any SummaryFormatter implementation."""

    def __init__(self, formatter: SummaryFormatter) -> None:
        """Initialize reporter with an object providing format_summary."""
        # Check callable attribute at runtime to guard dynamic callers.
        if not hasattr(formatter, "format_summary") or not callable(formatter.format_summary):
            raise TypeError("formatter must provide a callable format_summary method.")

        # Store collaborator implementing the SummaryFormatter protocol.
        self._formatter: SummaryFormatter = formatter

    def build_report(self, record_code: str, item_total: int) -> str:
        """Delegate summary formatting to the configured formatter."""
        # Delegate formatting directly to the protocol implementation.
        return self._formatter.format_summary(record_code=record_code, item_total=item_total)

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Verify structural compatibility and build a summary report.
    text_formatter: PlainTextSummaryFormatter = PlainTextSummaryFormatter()
    reporter: ShipmentReporter = ShipmentReporter(formatter=text_formatter)

    print("Matches protocol:", isinstance(text_formatter, SummaryFormatter))
    print("Report:", reporter.build_report(" ord-508 ", 7))
