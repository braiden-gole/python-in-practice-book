Chapter 6: Properties, Validations & Descriptor Protocol

When callers read, assign, or delete attributes on an object, plain public fields offer no guardrails against invalid data or out-of-order mutations. Python solves this with @property (getters, setters, and deleters) for single-class attributes and the descriptor protocol (__get__, __set__, __delete__, and __set_name__) for reusable attribute validation across multiple classes.

Why properties beat raw attributes: You can expose a clean attribute interface like shipment.number_of_items while running validation, normalization, or lifecycle checks automatically whenever the value is read, changed, or deleted.

When to reach for a descriptor: If the same validation rule such as a non-empty trimmed string or a positive non-boolean integer repeats across many classes or fields, encapsulating that logic in a descriptor class avoids repetitive property boilerplate.

Mechanism Key Hooks Primary Role Defensive Pitfall to Avoid
Property Getter @property def attr(self): Computes or returns validated internal state cleanly Referencing the wrong backing attribute name or mutating state on read
Property Setter @attr.setter def attr(self, val): Validates types, normalizes values, and guards state transitions on assignment Forgetting isinstance(val, bool) before checking isinstance(val, int)
Property Deleter @attr.deleter def attr(self): Controls or blocks del obj.attr instead of leaving dangling attributes Silently deleting required backing fields that getters assume exist
Data Descriptor __set_name__, __get__, __set__, __delete__ Reuses attribute validation and storage rules across multiple classes Storing per-instance values on self (the descriptor) instead of instance.__dict__ or a WeakKeyDictionary
Core Principles of Properties & Descriptors
  • Route initialization through setters: Assigning self.attr = initial_value inside __init__ runs the same type and range checks as later updates.
  • Handle del obj.attr intentionally: A deleter can reset a value to a safe default, transition state, or raise an explicit error when deletion is forbidden.
  • Keep per-instance data off the descriptor object: Descriptor instances live on the class, so store per-object values on the target instance rather than on the descriptor itself.
  • Use __set_name__ for automatic field naming: Python calls __set_name__(self, owner, name) when the class is created, giving the descriptor its attribute name automatically.

6.1 Getters, Setters, and Deleters with @property

A property groups getter, setter, and deleter methods under one attribute name. That lets you enforce lifecycle rules such as locking edits after dispatch or allowing resets only from a cancelled state while keeping caller code clean.

from enum import Enum
from typing import Union

class ShipmentStatus(str, Enum):
    """Allowed lifecycle states for an order shipment."""

    PENDING = "pending"
    DISPATCHED = "dispatched"
    CANCELLED = "cancelled"

class OrderShipment:
    """Manage shipment state transitions using properties, setters, and deleters."""

    def __init__(self, shipment_id: str, number_of_items: int) -> None:
        """Initialize a pending shipment with validated ID and item count."""
        # Initialize backing attributes before running property setters.
        self._shipment_id: str = ""
        self._number_of_items: int = 0
        self._status: ShipmentStatus = ShipmentStatus.PENDING

        # Assign through properties so validation runs consistently.
        self.id = shipment_id
        self.number_of_items = number_of_items
        self.status = ShipmentStatus.PENDING

    @property
    def id(self) -> str:
        """Return the normalized shipment identifier."""
        if not hasattr(self, "_shipment_id") or not self._shipment_id:
            raise AttributeError("Shipment identifier is not initialized.")
        return self._shipment_id

    @id.setter
    def id(self, candidate_id: str) -> None:
        """Validate and normalize the shipment ID while still pending."""
        if not isinstance(candidate_id, str):
            raise TypeError("Shipment ID must be a string.")

        if hasattr(self, "_status") and self._status is not ShipmentStatus.PENDING:
            raise ValueError(f"Cannot modify shipment ID when status is '{self._status.value}'.")

        normalized_id: str = candidate_id.strip().upper()
        if not normalized_id:
            raise ValueError("Shipment ID cannot be blank.")

        self._shipment_id = normalized_id

    @id.deleter
    def id(self) -> None:
        """Prevent deleting an active shipment identifier."""
        raise RuntimeError("Shipment ID cannot be deleted once created.")

    @property
    def number_of_items(self) -> int:
        """Return the number of items in the shipment."""
        if not hasattr(self, "_number_of_items") or self._number_of_items is None:
            raise AttributeError("Item count is not initialized.")
        return self._number_of_items

    @number_of_items.setter
    def number_of_items(self, item_count: int) -> None:
        """Validate and set a positive non-boolean item count while pending."""
        if hasattr(self, "_status") and self._status is not ShipmentStatus.PENDING:
            raise ValueError(f"Cannot update item count when status is '{self._status.value}'.")

        # Reject booleans explicitly because bool subclasses int in Python.
        if isinstance(item_count, bool) or not isinstance(item_count, int):
            raise TypeError("Item count must be a non-boolean integer.")

        if item_count <= 0:
            raise ValueError("Item count must be greater than zero.")

        self._number_of_items = item_count

    @number_of_items.deleter
    def number_of_items(self) -> None:
        """Reset item count to zero only when the shipment is cancelled."""
        if self._status is not ShipmentStatus.CANCELLED:
            raise ValueError(f"Cannot clear item count when status is '{self._status.value}'.")
        self._number_of_items = 0

    @property
    def status(self) -> ShipmentStatus:
        """Return the current shipment status."""
        if not hasattr(self, "_status") or self._status is None:
            raise AttributeError("Shipment status is not initialized.")
        return self._status

    @status.setter
    def status(self, next_status: Union[ShipmentStatus, str]) -> None:
        """Validate and transition shipment status across allowed states."""
        if isinstance(next_status, str) and not isinstance(next_status, ShipmentStatus):
            try:
                resolved_status: ShipmentStatus = ShipmentStatus(next_status.strip().lower())
            except ValueError as status_error:
                raise ValueError(f"Invalid shipment status '{next_status}'.") from status_error
        elif isinstance(next_status, ShipmentStatus):
            resolved_status = next_status
        else:
            raise TypeError("Shipment status must be a ShipmentStatus or status string.")

        if hasattr(self, "_status") and self._status is resolved_status:
            return

        if hasattr(self, "_status"):
            if self._status is not ShipmentStatus.PENDING:
                raise ValueError(
                    f"Cannot transition status from '{self._status.value}' to '{resolved_status.value}'."
                )
            if resolved_status not in (ShipmentStatus.DISPATCHED, ShipmentStatus.CANCELLED):
                raise ValueError(f"Unsupported transition to '{resolved_status.value}'.")

        self._status = resolved_status

    @status.deleter
    def status(self) -> None:
        """Reopen a cancelled shipment back to pending."""
        if self._status is not ShipmentStatus.CANCELLED:
            raise ValueError(f"Cannot reset status when shipment is '{self._status.value}'.")
        self._status = ShipmentStatus.PENDING

    def dispatch(self) -> None:
        """Mark a pending shipment as dispatched."""
        self.status = ShipmentStatus.DISPATCHED

    def cancel(self) -> None:
        """Mark a pending shipment as cancelled."""
        self.status = ShipmentStatus.CANCELLED

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Exercise getter, setter, and deleter behavior across a shipment lifecycle.
    order_pkg: OrderShipment = OrderShipment("shp-900", 4)

    order_pkg.number_of_items = 6
    order_pkg.dispatch()

    print(order_pkg.id, order_pkg.number_of_items, order_pkg.status.value)

    cancelled_pkg: OrderShipment = OrderShipment("shp-901", 3)
    cancelled_pkg.cancel()

    del cancelled_pkg.number_of_items

    print(cancelled_pkg.id, cancelled_pkg.number_of_items, cancelled_pkg.status.value)

6.2 Reusable Data Descriptors with __set_name__

When a descriptor defines both __get__ and __set__, Python treats it as a data descriptor, giving it priority over instance dictionary lookups. Using __set_name__ captures the attribute name automatically so you can reuse one descriptor across multiple fields and classes.

from typing import Optional, Type

class PositiveIntegerField:
    """Data descriptor enforcing positive non-boolean integer values per instance."""

    def __init__(self, allow_zero: bool = False) -> None:
        """Configure whether zero is permitted alongside positive integers."""
        # Reject booleans for the allow_zero configuration flag.
        if isinstance(allow_zero, bool):
            self._allow_zero: bool = allow_zero
        else:
            raise TypeError("allow_zero must be a boolean.")

        self._public_name: str = ""
        self._storage_attr: str = ""

    def __set_name__(self, owner_class: Type[object], attribute_name: str) -> None:
        """Record the bound attribute name when the descriptor is attached to a class."""
        # Derive a private storage key on the target instance.
        self._public_name = attribute_name
        self._storage_attr = f"_desc_{attribute_name}"

    def __get__(self, instance_obj: Optional[object], owner_class: Type[object]) -> object:
        """Return the descriptor for class access or the stored value for instance access."""
        # Return the descriptor itself when accessed via the class (e.g., Item.quantity).
        if instance_obj is None:
            return self

        if not self._storage_attr or not hasattr(instance_obj, self._storage_attr):
            raise AttributeError(f"Attribute '{self._public_name}' is not initialized.")

        return getattr(instance_obj, self._storage_attr)

    def __set__(self, instance_obj: object, candidate_value: object) -> None:
        """Validate candidate_value and store it on the target instance."""
        # Reject booleans explicitly because bool subclasses int in Python.
        if isinstance(candidate_value, bool) or not isinstance(candidate_value, int):
            raise TypeError(f"'{self._public_name}' must be a non-boolean integer.")

        minimum_allowed: int = 0 if self._allow_zero else 1

        if candidate_value < minimum_allowed:
            raise ValueError(
                f"'{self._public_name}' must be at least {minimum_allowed}."
            )

        setattr(instance_obj, self._storage_attr, candidate_value)

    def __delete__(self, instance_obj: object) -> None:
        """Prevent deleting validated numeric fields by default."""
        raise AttributeError(f"Cannot delete descriptor attribute '{self._public_name}'.")

class WarehouseBox:
    """Example model reusing PositiveIntegerField across two numeric attributes."""

    # Reuse the same descriptor class for unit quantity and priority weight.
    units_count = PositiveIntegerField(allow_zero=False)
    priority_rank = PositiveIntegerField(allow_zero=True)

    def __init__(self, units_count: int, priority_rank: int) -> None:
        """Initialize validated unit count and priority rank."""
        self.units_count = units_count
        self.priority_rank = priority_rank

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Create two boxes and verify independent per-instance values.
    box: WarehouseBox = WarehouseBox(units_count=10, priority_rank=0)
    warehouse_box: WarehouseBox = WarehouseBox(units_count=3, priority_rank=2)

    print("First box:", box.units_count, box.priority_rank)
    print("Second box:", warehouse_box.units_count, warehouse_box.priority_rank)

6.3 Normalized String Descriptor for Clean Text Fields

Descriptors can also normalize strings, trimming whitespace, enforcing casing, and rejecting blank values so every model using that field stores consistent data automatically.

from typing import Optional, Type

class UppercaseCodeField:
    """Data descriptor that validates non-empty strings and normalizes them to uppercase."""

    def __init__(self, minimum_length: int = 1) -> None:
        """Configure minimum character length after trimming whitespace."""
        # Reject booleans because bool subclasses int in Python.
        if isinstance(minimum_length, bool) or not isinstance(minimum_length, int):
            raise TypeError("minimum_length must be a non-boolean integer.")

        # Enforce a positive minimum length for validated codes.
        if minimum_length < 1:
            raise ValueError("minimum_length must be at least 1.")

        # Store minimum length and initialize attribute names bound later.
        self._minimum_length: int = minimum_length
        self._field_name: str = ""
        self._internal_attr: str = ""

    def __set_name__(self, owner_class: Type[object], attribute_name: str) -> None:
        """Store field name metadata when bound to a class."""
        # Save public attribute name and backing private attribute name.
        self._field_name = attribute_name
        self._internal_attr = f"_code_{attribute_name}"

    def __get__(self, instance_obj: Optional[object], owner_class: Type[object]) -> object:
        """Return the descriptor on class access or the stored uppercase string on instances."""
        # Return the descriptor object itself when accessed on the class.
        if instance_obj is None:
            return self

        # Fail clearly if the backing attribute has not been assigned yet.
        if not self._internal_attr or not hasattr(instance_obj, self._internal_attr):
            raise AttributeError(f"Code field '{self._field_name}' is not initialized.")

        # Read and return the normalized code stored on the instance.
        return getattr(instance_obj, self._internal_attr)

    def __set__(self, instance_obj: object, raw_code: object) -> None:
        """Validate, trim, uppercase, and store the code on the target instance."""
        # Reject non-string inputs before attempting string operations.
        if not isinstance(raw_code, str):
            raise TypeError(f"'{self._field_name}' must be a string.")

        # Strip surrounding whitespace and convert characters to uppercase.
        normalized_code: str = raw_code.strip().upper()

        # Reject codes shorter than the configured minimum length.
        if len(normalized_code) < self._minimum_length:
            raise ValueError(
                f"'{self._field_name}' must be at least {self._minimum_length} characters."
            )

        # Persist the validated code onto the instance backing attribute.
        setattr(instance_obj, self._internal_attr, normalized_code)

class BinLocation:
    """Storage location using UppercaseCodeField for aisle and rack codes."""

    # Bind two descriptor instances for aisle and rack identifiers.
    aisle_code = UppercaseCodeField(minimum_length=2)
    rack_code = UppercaseCodeField(minimum_length=2)

    def __init__(self, aisle_code: str, rack_code: str) -> None:
        """Initialize a bin location with normalized aisle and rack codes."""
        # Trigger descriptor validation and normalization during initialization.
        self.aisle_code = aisle_code
        self.rack_code = rack_code


# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Create a bin location with mixed-case padded inputs.
    storage_bin: BinLocation = BinLocation(aisle_code=" a12 ", rack_code=" r04 ")

    # Print the normalized aisle and rack codes.
    print("Location:", storage_bin.aisle_code, storage_bin.rack_code)
