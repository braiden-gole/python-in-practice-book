Chapter 16: Observability, Metrics & Audit Trails in OOP Systems

In production, knowing that a class ran is rarely enough operators need quantitative metrics, duration measurements, and immutable audit trails showing who triggered an action, what changed, and whether it succeeded. Dedicated telemetry collectors and audit recorders keep observability structured without polluting business logic.

Separating metrics from domain state: Counters and latency timers track system behavior over time, while audit entries capture accountable state transitions with correlation context and timestamps.

Safe telemetry under concurrency: Since metrics and audit logs are often updated across multiple requests or threads, internal counters and entry lists must be guarded and exposed as read-only snapshots.

Observability Pillar Primary Role Key Advantage Defensive Pitfall to Avoid
Metrics Registry Tracks named counters and duration samples across operations Exposes throughput, error rates, and latency trends cleanly Mutating raw internal dictionaries from outside the registry
Audit Trail Recorder Appends immutable records of significant state actions Provides a clear chronological trail for debugging and compliance Allowing retroactive mutation or missing actor/outcome fields
Operation Timer Measures elapsed execution time across a scoped block Records accurate durations on both success and failure paths Forgetting to record timing when an exception escapes the block
Correlation Context Attaches a request or workflow ID across metrics and audit events Links performance spikes directly to specific business operations Dropping correlation IDs at service or adapter boundaries
Core Principles of Metrics & Audit Trails
  • Keep audit entries immutable: Represent each audit record as a frozen dataclass with a UTC timestamp, actor, action, target, and outcome.
  • Measure both success and failure paths: Record operation durations and outcome counters even when an operation raises an exception.
  • Guard shared telemetry state with a lock: Synchronize counter increments, timing samples, and audit appends so concurrent callers stay consistent.
  • Validate metric names and labels early: Reject blank names, negative increments, or booleans before updating telemetry state.

16.1 Thread-Safe Metrics Registry & Scoped Timer

This metrics registry records validated counter increments and millisecond timing samples under a lock, while a context-managed timer records elapsed duration on both normal exit and exception.

import time
import threading

from decimal import Decimal
from dataclasses import dataclass
from types import TracebackType

@dataclass(frozen=True)
class TimingSummary:
    """Immutable summary of recorded duration samples in milliseconds."""

    number_of_samples: int
    total_ms: Decimal
    maximum_ms: Decimal

class MetricsRegistry:
    """Thread-safe collector for named counters and operation duration samples."""

    def __init__(self) -> None:
        """Initialize lock and empty metric stores."""
        # Protect counter and timing dictionaries against concurrent updates.
        self._lock: threading.Lock = threading.Lock()
        self._counters: dict[str, int] = {}
        self._timings_ms: dict[str, list[Decimal]] = {}

    @staticmethod
    def _clean_metric_name(name: object) -> str:
        """Validate and normalize a non-empty metric identifier."""
        # Reject non-string or whitespace-only metric names defensively.
        if not isinstance(name, str) or not name.strip():
            raise ValueError("metric_name must be a non-empty string.")

        # Normalize metric names to lowercase with trimmed whitespace.
        return name.strip().lower()

    def increment_counter(self, metric_name: str, step_amount: int = 1) -> int:
        """Increment a counter by step_amount and return the updated total."""
        # Validate metric name and non-boolean positive integer step.
        clean_name: str = self._clean_metric_name(metric_name)

        if isinstance(step_amount, bool) or not isinstance(step_amount, int):
            raise TypeError("step_amount must be a non-boolean integer.")

        if step_amount < 1:
            raise ValueError("step_amount must be greater than or equal to 1.")

        # Update counter atomically under lock.
        with self._lock:
            updated_value: int = self._counters.get(clean_name, 0) + step_amount

            self._counters[clean_name] = updated_value

            return updated_value

    def record_duration_ms(self, metric_name: str, duration_ms: Decimal) -> None:
        """Record a non-negative finite duration sample in milliseconds."""
        # Validate metric name and Decimal duration value.
        clean_name: str = self._clean_metric_name(metric_name)

        if isinstance(duration_ms, bool) or not isinstance(duration_ms, Decimal):
            raise TypeError("duration_ms must be a Decimal.")

        if not duration_ms.is_finite() or duration_ms < Decimal("0.00"):
            raise ValueError("duration_ms must be a non-negative finite Decimal.")

        # Append duration sample under lock.
        with self._lock:
            samples: list[Decimal] = self._timings_ms.setdefault(clean_name, [])
            samples.append(duration_ms)

    def counters_snapshot(self) -> dict[str, int]:
        """Return a copy of all counter totals."""
        # Read counters under lock so external mutations cannot race.
        with self._lock:
            return dict(self._counters)

    def timing_summary(self, metric_name: str) -> TimingSummary:
        """Return aggregated timing statistics for a recorded metric."""
        # Normalize name and compute summary under lock.
        clean_name: str = self._clean_metric_name(metric_name)

        with self._lock:
            samples: list[Decimal] = list(self._timings_ms.get(clean_name, []))

        if not samples:
            return TimingSummary(
                number_of_samples=0,
                total_ms=Decimal("0.000"),
                maximum_ms=Decimal("0.000"),
            )

        total_value: Decimal = sum(samples, start=Decimal("0.000"))
        maximum_value: Decimal = max(samples)

        return TimingSummary(
            number_of_samples=len(samples),
            total_ms=total_value,
            maximum_ms=maximum_value,
        )

class OperationTimer:
    """Context manager measuring elapsed milliseconds into a MetricsRegistry."""

    def __init__(self, registry: MetricsRegistry, metric_name: str) -> None:
        """Initialize timer with a MetricsRegistry and target metric name."""
        # Reject invalid registry or blank metric names defensively.
        if not isinstance(registry, MetricsRegistry):
            raise TypeError("registry must be a MetricsRegistry instance.")

        if not isinstance(metric_name, str) or not metric_name.strip():
            raise ValueError("metric_name must be a non-empty string.")

        self._registry: MetricsRegistry = registry
        self._metric_name: str = metric_name.strip().lower()
        self._start_perf_counter: float | None = None

    def __enter__(self) -> "OperationTimer":
        """Start high-resolution timer when entering the context block."""
        # Capture monotonic start timestamp.
        self._start_perf_counter = time.perf_counter()

        return self

    def __exit__(
        self,
        exception_type: type[BaseException] | None,
        exception_value: BaseException | None,
        exception_traceback: TracebackType | None,
    ) -> bool:
        """Record elapsed milliseconds in the registry and never suppress exceptions."""
        # Compute elapsed duration if timer was started.
        if self._start_perf_counter is not None:
            elapsed_seconds: float = max(0.0, time.perf_counter() - self._start_perf_counter)
            elapsed_ms: Decimal = Decimal(f"{elapsed_seconds * 1000.0:.3f}")

            self._registry.record_duration_ms(self._metric_name, elapsed_ms)
            self._start_perf_counter = None

        # Allow exceptions to propagate normally.
        return False

# Run this block only when executing the module directly.
if __name__ == "__main__":
    # Measure a timed operation and inspect recorded counters and timing summary.
    metrics_store: MetricsRegistry = MetricsRegistry()
    metrics_store.increment_counter("jobs_started", 2)

    with OperationTimer(metrics_store, "batch_sync_duration_ms"):
        total_sum: int = sum(range(10_000))
        _ = total_sum

    metrics_store.increment_counter("jobs_completed", 2)

    print("Counters:", metrics_store.counters_snapshot())
    print("Timing summary:", metrics_store.timing_summary("batch_sync_duration_ms"))

16.2 Immutable Audit Trail Recorder

An audit trail recorder captures structured, immutable events with correlation IDs and outcomes so operational actions can be traced cleanly.

import threading

from dataclasses import dataclass
from datetime import datetime, timezone

@dataclass(frozen=True)
class AuditEntry:
    """Immutable audit record capturing actor, action, target, outcome, and context."""

    correlation_id: str
    actor_name: str
    action_name: str
    target_resource: str
    outcome_status: str
    recorded_at_utc: datetime

    def __post_init__(self) -> None:
        """Validate non-empty strings, outcome label, and timezone-aware timestamp."""
        # Reject blank or non-string audit fields defensively.
        for field_label, field_value in (
            ("correlation_id", self.correlation_id),
            ("actor_name", self.actor_name),
            ("action_name", self.action_name),
            ("target_resource", self.target_resource),
        ):
            if not isinstance(field_value, str) or not field_value.strip():
                raise ValueError(f"{field_label} must be a non-empty string.")

        # Restrict outcome_status to explicit allowed values.
        if not isinstance(self.outcome_status, str):
            raise TypeError("outcome_status must be a string.")

        normalized_outcome: str = self.outcome_status.strip().lower()

        if normalized_outcome not in {"success", "failure", "denied"}:
            raise ValueError("outcome_status must be 'success', 'failure', or 'denied'.")

        # Require timezone-aware datetime for unambiguous audit ordering.
        if not isinstance(self.recorded_at_utc, datetime) or self.recorded_at_utc.tzinfo is None:
            raise ValueError("recorded_at_utc must be a timezone-aware datetime.")

        # Normalize string fields cleanly on the frozen record.
        object.__setattr__(self, "correlation_id", self.correlation_id.strip())
        object.__setattr__(self, "actor_name", self.actor_name.strip().lower())
        object.__setattr__(self, "action_name", self.action_name.strip().lower())
        object.__setattr__(self, "target_resource", self.target_resource.strip())
        object.__setattr__(self, "outcome_status", normalized_outcome)

class AuditTrailRecorder:
    """Thread-safe append-only recorder storing AuditEntry records."""

    def __init__(self) -> None:
        """Initialize lock and empty audit event list."""
        # Guard append and read operations with a dedicated lock.
        self._lock: threading.Lock = threading.Lock()
        self._entries: list[AuditEntry] = []

    def record_event(
        self,
        correlation_id: str,
        actor_name: str,
        action_name: str,
        target_resource: str,
        outcome_status: str,
    ) -> AuditEntry:
        """Create a timestamped AuditEntry and append it to the trail."""
        # Construct AuditEntry with current UTC timestamp and append under lock.
        new_entry: AuditEntry = AuditEntry(
            correlation_id=correlation_id,
            actor_name=actor_name,
            action_name=action_name,
            target_resource=target_resource,
            outcome_status=outcome_status,
            recorded_at_utc=datetime.now(timezone.utc),
        )

        with self._lock:
            self._entries.append(new_entry)

        return new_entry

    def list_entries(self) -> list[AuditEntry]:
        """Return a snapshot list of all recorded AuditEntry objects."""
        # Return shallow list copy under lock so callers cannot mutate internal list.
        with self._lock:
            return list(self._entries)

# Run this block only when executing the module directly.
if __name__ == "__main__":
    # Record sample audit events and print stored entries.
    trail: AuditTrailRecorder = AuditTrailRecorder()

    trail.record_event(
        correlation_id="corr-5001",
        actor_name="ops_bot",
        action_name="publish_schedule",
        target_resource="schedule/2026-11-23",
        outcome_status="success",
    )

    trail.record_event(
        correlation_id="corr-5002",
        actor_name="guest_user",
        action_name="delete_schedule",
        target_resource="schedule/2026-11-23",
        outcome_status="denied",
    )

    for audit_item in trail.list_entries():
        print("Audit entry:", audit_item)
