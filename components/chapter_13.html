Chapter 13: Configuration, Serialization & Boundary Adapters

External environment variables, JSON or CSV payloads, and third-party API schemas rarely match your domain model's invariants out of the box. Dedicated configuration objects, serializers, and boundary adapters translate untrusted external data into validated internal objects without leaking wire formats into core logic.

Isolating external formats: When raw dictionaries, environment strings, or external event payloads pass straight into domain classes, typos, missing keys, and type quirks spread across the codebase.

Adapters as strict translation gates: A boundary adapter parses and normalizes external representations on ingress and formats domain models cleanly on egress, rejecting invalid payloads immediately.

Boundary Component Primary Responsibility Key Advantage Defensive Pitfall to Avoid
Typed Configuration Loads and validates environment/runtime settings once at startup Fails fast on bad ports, blanks, or invalid modes before serving Reading raw os.environ lookups ad-hoc deep inside helper functions
Serialization Codec Converts domain records to and from JSON or structured dictionaries Preserves precision (such as Decimal) and field contracts Serializing floats for money/weight or allowing arbitrary unvalidated keys
Boundary Adapter Translates external wire payloads into internal domain objects Keeps third-party field names out of core business models Mutating raw input mappings in place or silently ignoring extra/bad fields
Normalizer Guard Trims whitespace, standardizes case, and checks numeric/bool types Prevents subtle string/type mismatches across system boundaries Treating True/False as valid integers or skipping blank-string checks
Core Principles of Boundary & Serialization Design
  • Validate once at the boundary: Parse strings, check types, and enforce value bounds as data enters the system so inner services work with clean types.
  • Keep wire schemas separate from domain models: Map external field aliases inside an adapter rather than cluttering domain objects with transport details.
  • Preserve exact numeric representations: Use Decimal when parsing or serializing weights, rates, or quantities instead of binary floating-point numbers.
  • Fail explicitly on malformed payloads: Raise clear TypeError or ValueError exceptions on missing fields, wrong types, or invalid JSON.

13.1 Validated Runtime Configuration Object

A configuration object centralizes environment parsing and invariant checks so invalid runtime settings are caught immediately at startup.

from __future__ import annotations
                    
import os
from dataclasses import dataclass

@dataclass(frozen=True)
class ServiceRuntimeConfiguration:
    """Immutable runtime settings validated for type, range, and non-empty values."""

    service_environment: str
    worker_concurrency: int
    request_timeout_seconds: int

    def __post_init__(self) -> None:
        """Validate environment label, worker count, and timeout bounds."""
        # Reject non-string or blank environment names defensively.
        if not isinstance(self.service_environment, str) or not self.service_environment.strip():
            raise ValueError("service_environment must be a non-empty string.")

        # Reject booleans explicitly because bool subclasses int in Python.
        if isinstance(self.worker_concurrency, bool) or not isinstance(self.worker_concurrency, int):
            raise TypeError("worker_concurrency must be a non-boolean integer.")

        # Require at least one worker process or thread.
        if self.worker_concurrency < 1:
            raise ValueError("worker_concurrency must be greater than or equal to 1.")

        # Reject booleans and non-integers for timeout configuration.
        if isinstance(self.request_timeout_seconds, bool) or not isinstance(self.request_timeout_seconds, int):
            raise TypeError("request_timeout_seconds must be a non-boolean integer.")

        # Enforce a positive timeout window in seconds.
        if self.request_timeout_seconds <= 0:
            raise ValueError("request_timeout_seconds must be greater than zero.")

    @classmethod
    def load_env(cls, mapping: dict[str, str] | None = None) -> "ServiceRuntimeConfiguration":
        """Build ServiceRuntimeConfiguration from an explicit mapping or os.environ."""
        # Select provided mapping for deterministic testing or fall back to os.environ.
        source_map: dict[str, str] = dict(os.environ) if mapping is None else mapping

        if not isinstance(source_map, dict):
            raise TypeError("env_mapping must be a dictionary or None.")

        environment_name: str = source_map.get("SERVICE_ENV", "staging")

        workers: str = source_map.get("WORKER_CONCURRENCY", "4")
        timeout: str = source_map.get("REQUEST_TIMEOUT_SECONDS", "30")

        # Parse integer settings defensively before constructing the config object.
        try:
            parsed_workers: int = int(workers.strip())
        except ValueError as worker_parse_error:
            raise ValueError(f"Invalid WORKER_CONCURRENCY value: {workers!r}.") from worker_parse_error

        try:
            parsed_timeout: int = int(timeout.strip())
        except ValueError as timeout_parse_error:
            raise ValueError(
                f"Invalid REQUEST_TIMEOUT_SECONDS value: {timeout!r}."
            ) from timeout_parse_error

        # Return validated immutable configuration instance.
        return cls(
            service_environment=environment_name.strip().lower(),
            worker_concurrency=parsed_workers,
            request_timeout_seconds=parsed_timeout,
        )

13.2 JSON Serialization & External Payload Adapter

A boundary adapter translates an external JSON payload with third-party field names into a clean internal model and serializes it back to JSON deterministically.

import json

from dataclasses import dataclass
from decimal import Decimal, InvalidOperation

@dataclass(frozen=True)
class ManifestParcelModel:
    """Validated internal model representing a manifest parcel item."""

    parcel_id: str
    weight_kg: Decimal
    priority_flag: bool

    def __post_init__(self) -> None:
        """Validate identifier, positive finite Decimal weight, and boolean flag."""
        # Reject non-string or blank parcel identifiers defensively.
        if not isinstance(self.parcel_id, str) or not self.parcel_id.strip():
            raise ValueError("parcel_identifier must be a non-empty string.")

        # Reject booleans and non-Decimal weights defensively.
        if isinstance(self.weight_kg, bool) or not isinstance(self.weight_kg, Decimal):
            raise TypeError("declared_weight_kg must be a Decimal.")

        # Reject NaN, Infinity, zero, or negative parcel weights.
        if not self.weight_kg.is_finite() or self.weight_kg <= Decimal("0.00"):
            raise ValueError("declared_weight_kg must be a positive finite Decimal.")

        # Reject non-boolean priority flags defensively.
        if not isinstance(self.priority_flag, bool):
            raise TypeError("priority_flag must be a boolean.")

class ExternalManifestAdapter:
    """Adapter converting external JSON payloads to and from ManifestParcelModel."""

    def parse_json_payload(self, json_text: str) -> ManifestParcelModel:
        """Parse an external JSON payload string into a validated ManifestParcelModel."""
        # Reject non-string JSON inputs defensively.
        if not isinstance(json_text, str) or not json_text.strip():
            raise ValueError("raw_json_text must be a non-empty JSON string.")

        # Decode JSON text into a Python structure and chain parse errors.
        try:
            decoded_payload: object = json.loads(json_text)
        except json.JSONDecodeError as json_error:
            raise ValueError(f"Malformed JSON payload: {json_error.msg}.") from json_error

        # Require a JSON object (dictionary) at the root.
        if not isinstance(decoded_payload, dict):
            raise TypeError("Decoded JSON payload must be a JSON object.")

        # Extract external keys ('tracking_id', 'weight_kg', 'express') into domain fields.
        identifier: object = decoded_payload.get("tracking_id")
        weights: object = decoded_payload.get("weight_kg")
        express: object = decoded_payload.get("express", False)

        if not isinstance(identifier, str) or not identifier.strip():
            raise ValueError("Payload 'tracking_id' must be a non-empty string.")

        if isinstance(weights, bool) or not isinstance(weights, (str, int, Decimal)):
            raise TypeError("Payload 'weight_kg' must be a string, int, or Decimal.")

        # Convert weight into Decimal without losing precision.
        try:
            parsed_weight: Decimal = (
                weights
                if isinstance(weights, Decimal)
                else Decimal(str(weights).strip())
            )
        except (InvalidOperation, ValueError) as decimal_error:
            raise ValueError(
                f"Invalid numeric weight in payload: {weights!r}."
            ) from decimal_error

        if not isinstance(express, bool):
            raise TypeError("Payload 'express' must be a boolean.")

        # Return normalized internal domain model.
        return ManifestParcelModel(
            parcel_id=identifier.strip().upper(),
            weight_kg=parsed_weight,
            priority_flag=express,
        )

    def to_json_payload(self, parcel_model: ManifestParcelModel) -> str:
        """Serialize a ManifestParcelModel into a clean JSON string."""
        # Reject objects that are not ManifestParcelModel instances.
        if not isinstance(parcel_model, ManifestParcelModel):
            raise TypeError("parcel_model must be a ManifestParcelModel instance.")

        # Serialize Decimal as string so exact precision is preserved across wire formats.
        serialized_dict: dict[str, object] = {
            "parcel_identifier": parcel_model.parcel_id,
            "declared_weight_kg": str(parcel_model.weight_kg),
            "priority_flag": parcel_model.priority_flag,
        }

        return json.dumps(serialized_dict, sort_keys=True)

# Run this block only when executing the module directly.
if __name__ == "__main__":
    # Parse an external JSON payload via the adapter and serialize it back to JSON.
    adapter: ExternalManifestAdapter = ExternalManifestAdapter()
    incoming_json: str = '{"tracking_id": " trk-882 ", "weight_kg": "12.450", "express": true}'

    domain_parcel: ManifestParcelModel = adapter.parse_json_payload(incoming_json)
    outgoing_json: str = adapter.to_json_payload(domain_parcel)

    print("Domain model:", domain_parcel)
    print("Serialized JSON:", outgoing_json)
