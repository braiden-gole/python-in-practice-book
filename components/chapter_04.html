Chapter 4: Data Classes, Slots & Immutable Value Objects

Once you understand how mutable entities protect lifecycle state, the next step is modeling value objects compact structures defined by their data rather than a separate object identity. Pairing @dataclass(frozen=True) with __post_init__ and __slots__ keeps data predictable, validated, and memory-efficient.

What makes a value object distinct: Two instances of a value object are interchangeable whenever their normalized fields match—such as a MoneyAmount of $25.00 CAD or a ShipmentLineItem with SKU GLASS-042 and quantity 2.

Why immutability and slots matter together: Frozen instances prevent accidental mutation after construction, while __slots__ avoids per-instance __dict__ overhead and blocks typos from creating stray attributes silently.

Pattern Mechanism / Syntax Primary Role Defensive Pitfall to Avoid
Frozen Dataclass @dataclass(frozen=True) Generates __init__, __repr__, __eq__, and __hash__ while blocking attribute reassignment Using normal self.attr = ... inside __post_init__ instead of object.__setattr__
Post-Init Guard def __post_init__(self) -> None: Validates types, normalizes strings/decimals, and enforces invariants at creation time Allowing NaN/Infinity Decimal values or bool masquerading as int
Slotted Storage __slots__ or slots=True Replaces per-instance __dict__ with fixed slot descriptors to save memory and catch typos Storing mutable list or dict fields inside an otherwise frozen object
Immutable Collections tuple[...], frozenset[...] Keeps nested collections read-only so callers cannot mutate inner items Passing raw mutable lists into a frozen record without normalizing
Core Principles of Value Objects & Slots
  • Value equality & hashability: Frozen dataclasses with hashable fields can be compared with ==, stored in set collections, and used as dict keys safely.
  • object.__setattr__ in __post_init__: Use object.__setattr__(self, "field", normalized_value) when normalizing fields after construction on a frozen dataclass.
  • Slots reduce overhead & typos: Enabling slots=True avoids per-instance __dict__ allocation and immediately raises AttributeError if someone assigns a misspelled attribute name.
  • Return new instances instead of mutating: Operations like adding two amounts should return a new validated object rather than mutating existing state in place.

4.1 Frozen Data Classes and __post_init__ Normalization

A frozen dataclass generates boilerplate methods automatically while letting __post_init__ enforce domain rules before the object is handed to callers. Use object.__setattr__ when writing normalized values onto a frozen instance.

from dataclasses import dataclass
from decimal import Decimal, InvalidOperation, ROUND_HALF_UP

@dataclass(frozen=True)
class MoneyAmount:
    """Immutable monetary value object defined by an exact amount and currency code."""

    amount: Decimal
    currency: str

    def __post_init__(self) -> None:
        """Validate and normalize monetary amount and currency invariants."""
        # Reject boolean values explicitly because bool is a subclass of int.
        if isinstance(self.amount, bool):
            raise TypeError("Monetary amount cannot be a boolean.")

        # Convert supported input types into a Decimal cleanly.
        try:
            if isinstance(self.amount, Decimal):
                parsed_amount: Decimal = self.amount
            elif isinstance(self.amount, (int, float, str)):
                parsed_amount = Decimal(str(self.amount).strip())
            else:
                raise TypeError("Monetary amount must be a Decimal, int, float, or str.")
        except InvalidOperation as parse_error:
            raise ValueError(f"Invalid monetary amount: {self.amount}.") from parse_error

        # Reject non-finite Decimal values such as NaN or Infinity.
        if not parsed_amount.is_finite():
            raise ValueError("Monetary amount must be a finite number.")

        # Normalize to two decimal places using half-up rounding.
        normalized_amount: Decimal = parsed_amount.quantize(
            Decimal("0.01"),
            rounding=ROUND_HALF_UP,
        )

        # Reject non-string currency codes.
        if not isinstance(self.currency, str):
            raise TypeError("Currency code must be a string.")

        # Normalize currency code whitespace and casing.
        normalized_currency: str = self.currency.strip().upper()

        # Require a three-letter alphabetic currency code.
        if len(normalized_currency) != 3 or not normalized_currency.isalpha():
            raise ValueError("Currency code must be a three-letter alphabetic code.")

        # Assign normalized values on the frozen instance via object.__setattr__.
        object.__setattr__(self, "amount", normalized_amount)
        object.__setattr__(self, "currency", normalized_currency)

    def add(self, other_amount: "MoneyAmount") -> "MoneyAmount":
        """Return a new MoneyAmount sum when currencies match."""
        # Ensure the other operand is a MoneyAmount instance.
        if not isinstance(other_amount, MoneyAmount):
            raise TypeError("Can only add another MoneyAmount instance.")

        # Prevent mixing different currencies silently.
        if self.currency != other_amount.currency:
            raise ValueError(
                f"Cannot add currency '{other_amount.currency}' to '{self.currency}'."
            )

        # Return a new immutable instance with the combined amount.
        return MoneyAmount(amount=self.amount + other_amount.amount, currency=self.currency)

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Create two MoneyAmount instances and compute their sum.
    item_price: MoneyAmount = MoneyAmount(amount="19.995", currency=" cad ")
    shipping_cost: MoneyAmount = MoneyAmount(amount=5, currency="CAD")
    total_amount: MoneyAmount = item_price.add(shipping_cost)

    # Display normalized values and equality check.
    print(item_price.amount, item_price.currency)
    print(total_amount.amount, total_amount.currency)
    print("Equal to $20.00 CAD:", item_price == MoneyAmount(amount="20.00", currency="CAD"))

4.2 Combining frozen=True with slots=True

Passing slots=True to @dataclass stores fields in slots instead of a per-instance __dict__. This reduces memory footprint for large collections of objects and prevents accidental creation of new attributes via typos.

from dataclasses import dataclass, field

@dataclass(frozen=True, slots=True)
class ShipmentLineItem:
    """Immutable slotted value object representing a single product line item."""

    sku_code: str
    quantity: int
    tags: tuple[str, ...] = field(default_factory=tuple)

    def __post_init__(self) -> None:
        """Validate SKU code, positive integer quantity, and normalized tags."""
        # Reject non-string SKU codes.
        if not isinstance(self.sku_code, str):
            raise TypeError("SKU code must be a string.")

        # Normalize whitespace and uppercase the SKU code.
        normalized_sku: str = self.sku_code.strip().upper()

        # Require a non-empty SKU code.
        if not normalized_sku:
            raise ValueError("SKU code cannot be blank.")

        # Reject booleans explicitly because bool is a subclass of int.
        if isinstance(self.quantity, bool) or not isinstance(self.quantity, int):
            raise TypeError("Quantity must be a non-boolean integer.")

        # Require a strictly positive item quantity.
        if self.quantity <= 0:
            raise ValueError("Quantity must be greater than zero.")

        # Normalize tag strings into a clean tuple of non-empty lowercase labels.
        normalized_tags: list[str] = []

        for tag in self.tags:
            if not isinstance(tag, str):
                raise TypeError("Each tag must be a string.")

            cleaned_tag: str = tag.strip().casefold()

            if cleaned_tag:
                normalized_tags.append(cleaned_tag)

        # Write normalized fields onto the frozen slotted instance.
        object.__setattr__(self, "sku_code", normalized_sku)
        object.__setattr__(self, "tags", tuple(normalized_tags))

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Construct a frozen slotted line item with normalized tags.
    fragile_line: ShipmentLineItem = ShipmentLineItem(
        sku_code=" glass-042 ",
        quantity=2,
        tags=("Fragile", "  handle-with-care "),
    )

    # Display normalized attributes.
    print(fragile_line.sku_code, fragile_line.quantity, fragile_line.tags)

4.3 Manual __slots__ in Plain Classes

When writing a custom class without @dataclass, declaring __slots__ restricts allowed attributes to the listed names. Keep every slot name explicitly declared and avoid creating stray attributes dynamically.

class CoordinatePoint:
    """Lightweight slotted point class with strict attribute names and validation."""

    # Declare allowed instance attributes explicitly to avoid per-instance __dict__.
    __slots__ = ("_latitude", "_longitude")

    def __init__(self, latitude: float, longitude: float) -> None:
        """Initialize and validate geographic latitude and longitude coordinates."""
        # Reject booleans and non-numeric values for latitude.
        if isinstance(latitude, bool) or not isinstance(latitude, (int, float)):
            raise TypeError("Latitude must be a number.")

        # Reject booleans and non-numeric values for longitude.
        if isinstance(longitude, bool) or not isinstance(longitude, (int, float)):
            raise TypeError("Longitude must be a number.")

        lat_value: float = float(latitude)
        lon_value: float = float(longitude)

        # Enforce valid geographic coordinate bounds.
        if not (-90.0 <= lat_value <= 90.0):
            raise ValueError("Latitude must be between -90 and 90 degrees.")

        if not (-180.0 <= lon_value <= 180.0):
            raise ValueError("Longitude must be between -180 and 180 degrees.")

        # Store validated coordinates in slot attributes.
        self._latitude: float = lat_value
        self._longitude: float = lon_value

    @property
    def latitude(self) -> float:
        """Return the validated latitude in degrees."""
        return self._latitude

    @property
    def longitude(self) -> float:
        """Return the validated longitude in degrees."""
        return self._longitude

    def __eq__(self, against: object) -> bool:
        """Return True when comparing two CoordinatePoint instances with matching values."""
        # Delegate to NotImplemented for unrelated types.
        if not isinstance(against, CoordinatePoint):
            return NotImplemented

        return self._latitude == against._latitude and self._longitude == against._longitude

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Create a coordinate point and verify property access.
    office_location: CoordinatePoint = CoordinatePoint(43.4516, -80.4925)
    
    print(office_location.latitude, office_location.longitude)
