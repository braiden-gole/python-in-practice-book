Chapter 10: __init_subclass__, Class Decorators & Metaclasses

In Python, classes themselves are objects created at class-definition time. Hooks like __init_subclass__, class decorators, and metaclasses let you validate subclass contracts, register plugins automatically, or inspect class attributes as soon as a class is defined.

Choosing the simplest hook that fits: Start with __init_subclass__ for subclass rules and plugin registration, reach for a class decorator when transforming or annotating individual classes cleanly, and reserve metaclasses for deep class creation control when simpler hooks are not enough.

Fail fast at class definition time: Enforcing required class attributes or unique registry keys when a class is created catches configuration mistakes immediately when the module loads rather than deep inside a runtime request.

Mechanism When It Runs Primary Strength Defensive Pitfall to Avoid
__init_subclass__ Whenever a direct subclass is created Clean subclass validation and automatic plugin registration without a metaclass Forgetting super().__init_subclass__(**kwargs) in multi-level hierarchies
Class Decorator Immediately after the decorated class is constructed Explicit, readable per-class wrapping, tagging, or registry attachment Mutating shared mutable defaults across multiple decorated classes
Metaclass (type) During class object construction (__new__ / __init__) Controls class namespace, bases, and metaclass-level behavior Over-engineering simple validation or registration that __init_subclass__ handles
Registry Lookup At class registration and lookup time Maps normalized keys to concrete handler or parser classes Allowing duplicate keys or blank/non-string registry identifiers
Core Principles of Class Customization
  • Prefer __init_subclass__ over custom metaclasses: For subclass checks and registries, __init_subclass__ keeps hierarchies clear and avoids metaclass conflicts.
  • Always call super().__init_subclass__(**kwargs): Forwarding keyword arguments preserves cooperative subclass initialization across inheritance chains.
  • Validate class attributes and keys defensively: Check types, strip/normalize identifiers, and reject duplicate registrations right at definition time.
  • Keep class-creation hooks predictable: Avoid hidden side effects or silent overwrites when registering classes into a lookup table.

10.1 Subclass Validation and Registration with __init_subclass__

Defining __init_subclass__ on a base class lets you require a normalized handler_code attribute on every subclass and register it automatically for lookup.

from typing import ClassVar, Optional

class ShipmentActionHandler:
    """Base handler registering subclasses by a validated handler_code."""

    # Store registered subclass types keyed by normalized handler code.
    handler_code: ClassVar[Optional[str]] = None
    _handler_registry: ClassVar[dict[str, type["ShipmentActionHandler"]]] = {}
    
    def __init_subclass__(cls, **keyword_arguments: object) -> None:
        """Validate handler_code and register concrete subclasses automatically."""
        # Forward keyword arguments along the inheritance chain first.
        super().__init_subclass__(**keyword_arguments)

        # Read handler_code declared on the subclass itself.
        handler_code_value: object = cls.__dict__.get("handler_code")

        # Require concrete subclasses to define a non-empty string handler_code.
        if not isinstance(handler_code_value, str):
            raise TypeError(f"{cls.__name__} must define a string 'handler_code'.")

        # Normalize code casing and reject blank values.
        normalized_code: str = handler_code_value.strip().upper()

        if not normalized_code:
            raise ValueError(f"{cls.__name__} 'handler_code' cannot be blank.")

        # Reject duplicate handler codes so registrations never collide silently.
        if normalized_code in cls._handler_registry:
            raise ValueError(f"Duplicate handler_code '{normalized_code}' in {cls.__name__}.")

        # Store normalized code on the subclass and register it.
        cls.handler_code = normalized_code
        cls._handler_registry[normalized_code] = cls

    @classmethod
    def resolve_handler(cls, lookup_code: str) -> type["ShipmentActionHandler"]:
        """Look up a registered handler class by normalized code."""
        # Reject non-string lookup codes defensively.
        if not isinstance(lookup_code, str):
            raise TypeError("lookup_code must be a string.")

        # Normalize lookup input before checking the registry.
        normalized_code: str = lookup_code.strip().upper()

        if normalized_code not in cls._handler_registry:
            raise KeyError(f"Unknown handler code: '{normalized_code}'.")

        # Return the matching registered handler class.
        return cls._handler_registry[normalized_code]

    @staticmethod
    def _normalize_reference(shipment_reference: object) -> str:
        """Validate and normalize a non-empty shipment reference string."""
        # Reject non-string shipment references defensively.
        if not isinstance(shipment_reference, str):
            raise TypeError("shipment_reference must be a string.")

        # Normalize whitespace and casing while rejecting blank values.
        cleaned_reference: str = shipment_reference.strip().upper()

        if not cleaned_reference:
            raise ValueError("shipment_reference cannot be blank.")

        # Return normalized reference code.
        return cleaned_reference

    def execute_action(self, shipment_reference: str) -> str:
        """Execute a validated action for a shipment reference."""
        # Normalize shipment reference before building action output.
        cleaned_reference: str = self._normalize_reference(shipment_reference)

        # Return formatted action confirmation.
        return f"{self.handler_code}: processed {cleaned_reference}"


class HoldShipmentHandler(ShipmentActionHandler):
    """Concrete handler placing a shipment on hold with a validated reason."""

    handler_code = "hold_parcel"

    def __init__(self, hold_reason: str = "inspection_required") -> None:
        """Initialize handler with a validated non-empty hold reason."""
        # Reject non-string hold reasons defensively.
        if not isinstance(hold_reason, str):
            raise TypeError("hold_reason must be a string.")

        # Normalize whitespace and reject blank hold reasons.
        cleaned_reason: str = " ".join(hold_reason.strip().split())

        if not cleaned_reason:
            raise ValueError("hold_reason cannot be blank.")

        # Store normalized hold reason on the handler instance.
        self._hold_reason: str = cleaned_reason

    @property
    def hold_reason(self) -> str:
        """Return the normalized hold reason."""
        # Expose hold reason via read-only property.
        return self._hold_reason

    def execute_action(self, shipment_reference: str) -> str:
        """Record a hold placement for the validated shipment reference."""
        # Normalize shipment reference before formatting hold status.
        cleaned_reference: str = self._normalize_reference(shipment_reference)

        # Return hold confirmation including the configured hold reason.
        return f"{self.handler_code}: {cleaned_reference} placed on hold ({self._hold_reason})"


class ReleaseShipmentHandler(ShipmentActionHandler):

    def __init__(self, clearance_badge: str = "OPS-CLEAR") -> None:
        """Initialize handler with a validated clearance badge identifier."""
        # Reject non-string clearance badge identifiers defensively.
        if not isinstance(clearance_badge, str):

        # Normalize casing and reject blank badge identifiers.

        if not cleaned_badge:
            raise ValueError("clearance_badge cannot be blank.")

        # Store normalized clearance badge on the handler instance.
        self._clearance_badge: str = cleaned_badge

    @property
    def clearance_badge(self) -> str:
        """Return the normalized clearance badge identifier."""
        # Expose clearance badge via read-only property.
        return self._clearance_badge

    def execute_action(self, shipment_reference: str) -> str:
        """Release a held shipment for dispatch using the validated clearance badge."""
        # Normalize shipment reference before formatting release status.

10.2 Class Decorators and Custom Metaclasses

A class decorator attaches metadata or behavior after a class is built, while a metaclass customizes class creation through type.__new__ or type.__init__.

from typing import Callable, ClassVar, TypeVar

ClassType = TypeVar("ClassType", bound=type)

def tag_schema_version(schema_version: int) -> Callable[[ClassType], ClassType]:
    """Class decorator attaching a validated non-boolean integer schema_version."""
    # Reject booleans explicitly because bool subclasses int in Python.
    if isinstance(schema_version, bool) or not isinstance(schema_version, int):
        raise TypeError("schema_version must be a non-boolean integer.")

    # Require a positive schema version number.
    if schema_version <= 0:
        raise ValueError("schema_version must be greater than zero.")

    def decorate_class(target_class: ClassType) -> ClassType:
        """Attach normalized schema_version onto the decorated class."""
        # Bind validated version attribute onto the class object.
        setattr(target_class, "schema_version", schema_version)

        # Return decorated class reference.
        return target_class

    # Return decorator function.
    return decorate_class

class AuditFieldMeta(type):
    """Metaclass ensuring every class using it declares a non-empty tuple of audit fields."""

    def __new__(
        meta_class: type["AuditFieldMeta"],
        class_name: str,
        base_classes: tuple[type, ...],
        class_namespace: dict[str, object],
        **extra_kwargs: object,
    ) -> "AuditFieldMeta":
        """Validate required_audit_fields before constructing the new class object."""
        # Create the class via type.__new__ first.
        created_class = super().__new__(
            meta_class,
            class_name,
            base_classes,
            class_namespace,
            **extra_kwargs,
        )

        # Skip validation on the base marker class itself.
        if class_name == "AuditedRecordBase":
            return created_class

        # Read declared audit fields from the class namespace.
        fields: object = class_namespace.get("required_audit_fields")

        if not isinstance(fields, tuple) or len(fields) == 0:
            raise TypeError(
                f"{class_name} must define a non-empty tuple 'required_audit_fields'."
            )

        # Validate every field name is a non-empty string.
        validated_fields: list[str] = []

        for field_entry in fields:
            if not isinstance(field_entry, str) or not field_entry.strip():
                raise ValueError(f"Invalid audit field in {class_name}: {field_entry!r}.")

            validated_fields.append(field_entry.strip())

        # Store normalized tuple on the created class.
        setattr(created_class, "required_audit_fields", tuple(validated_fields))

        # Return validated class object.
        return created_class

class AuditedRecordBase(metaclass=AuditFieldMeta):
    """Base class using AuditFieldMeta to enforce audit field declarations."""

    required_audit_fields: ClassVar[tuple[str, ...]] = ("created_by",)
    schema_version: ClassVar[int] = 1

    def __init__(self, manifest_code: str, audit_metadata: dict[str, str]) -> None:
        """Initialize a record and verify all required audit fields are present."""
        # Reject non-string manifest codes defensively.
        if not isinstance(manifest_code, str):
            raise TypeError("manifest_code must be a string.")

        # Normalize and reject blank manifest codes.
        cleaned_code: str = manifest_code.strip().upper()
        if not cleaned_code:
            raise ValueError("manifest_code cannot be blank.")

        # Reject non-dict audit metadata mappings.
        if not isinstance(audit_metadata, dict):
            raise TypeError("audit_metadata must be a dictionary.")

        # Validate every required audit field exists with a non-empty string value.
        normalized_audit: dict[str, str] = {}

        for required_key in type(self).required_audit_fields:
            if required_key not in audit_metadata:
                raise ValueError(f"Missing required audit field '{required_key}'.")

            value: object = audit_metadata[required_key]

            if not isinstance(value, str) or not value.strip():
                raise ValueError(f"Audit field '{required_key}' must be a non-empty string.")

            normalized_audit[required_key] = value.strip()

        # Store validated manifest identifier and audit values.
        self._manifest_code: str = cleaned_code
        self._audit_metadata: dict[str, str] = normalized_audit

    @property
    def manifest_code(self) -> str:
        """Return the normalized manifest code."""
        # Expose manifest code via read-only property.
        return self._manifest_code

    @property
    def audit_metadata(self) -> dict[str, str]:
        """Return a shallow copy of validated audit metadata."""
        # Return copy so external callers cannot mutate internal state.
        return dict(self._audit_metadata)

    def summarize_record(self) -> str:
        """Format a summary line including schema version and audited fields."""
        # Format key-value audit pairs deterministically.
        audit_summary: str = ", ".join(
            f"{field_name}={field_value}"
            for field_name, field_value in self._audit_metadata.items()
        )

        # Return formatted record summary string.
        return f"v{type(self).schema_version} {self._manifest_code} [{audit_summary}]"

@tag_schema_version(2)
class DispatchManifestRecord(AuditedRecordBase):
    """Versioned record class combining a metaclass check and class decorator."""

    required_audit_fields: ClassVar[tuple[str, ...]] = ("dispatched_by", "warehouse_code")
