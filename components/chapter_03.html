Chapter 3: Class Architecture, Invariants & Object Lifecycle

Once you can type-hint and normalize individual values, the next step is grouping related data and behavior into cohesive classes. A well-designed class protects its internal rules called invariants from the moment an object is constructed through every state transition during its lifetime.

What makes a class cohesive: Every attribute and method on a class should serve one clear responsibility. If a class juggles unrelated tasks like file parsing, network requests, and UI formatting at once, split those responsibilities into focused collaborator objects.

Class invariants at a glance: An invariant is a condition that must remain true whenever an object is created or mutated—for example, a non-empty SKU code, a non-negative stock count, or a valid lifecycle status such as "active", "reserved", or "discontinued".

Concept Mechanism / Syntax Primary Role Defensive Pitfall to Avoid
Instance State self.attribute: Type in __init__ Stores per-object data with explicit type hints Leaving attributes unvalidated or accepting bool as int
Class Attribute ALLOWED_STATUSES: frozenset[str] on class Shares immutable configuration or constants across instances Mutating a shared list or dict in place across instances
Factory Constructor @classmethod def from_...(cls, ...) -> Self Parses raw inputs (such as strings or records) into a valid instance Bypassing validation rules when building from external text
Identity vs. Equality is vs. == (__eq__) Distinguishes the same object in memory from equal domain values Using is to compare strings, numbers, or domain objects
State Transitions Explicit methods (reserve(), restock()) Moves objects through valid states while preserving invariants Allowing arbitrary status jumps or negative balances
Core Principles of Class Lifecycle Design
  • Fail-fast construction: Validate arguments inside __init__ so an invalid object can never exist in memory.
  • @classmethod factories: Use @classmethod with cls when constructing instances from alternative formats (like raw strings or CSV lines) and delegate directly to cls(...) so invariants stay enforced.
  • Identity (is) vs. equality (==): is checks whether two references point to the exact same object in memory; == compares value equality through __eq__.
  • Controlled state transitions: Encapsulate state changes behind explicit methods that verify preconditions before mutating attributes.

3.1 Constructing Objects and Enforcing Invariants

When you call a class like InventoryItem(...), Python allocates a new instance and runs __init__ to initialize its state. Checking types and business rules right inside __init__ guarantees that every live instance starts in a valid state.

class InventoryItem:
    """Represent a tracked warehouse item with enforced state invariants."""

    # Store allowed lifecycle states as an immutable frozenset on the class.
    VALID_STATUSES: frozenset[str] = frozenset({"active", "reserved", "discontinued"})

    def __init__(self, sku_code: str, item: str, quantity: int, status: str = "active") -> None:
        """Initialize and validate all required instance attributes."""
        # Reject non-string SKU identifiers early.
        if not isinstance(sku_code, str):
            raise TypeError("SKU code must be a string.")

        # Normalize whitespace and uppercase the SKU for consistent lookup.
        normalized_sku: str = sku_code.strip().upper()

        # Ensure the SKU is non-empty after trimming whitespace.
        if not normalized_sku:
            raise ValueError("SKU code cannot be blank.")

        # Reject non-string item names before normalizing.
        if not isinstance(item, str):
            raise TypeError("Item name must be a string.")

        # Collapse repeated internal spaces and trim surrounding whitespace.
        normalized_name: str = " ".join(item.strip().split())

        # Reject blank item names.
        if not normalized_name:
            raise ValueError("Item name cannot be blank.")

        # Check bool first because bool subclasses int in Python.
        if isinstance(quantity, bool) or not isinstance(quantity, int):
            raise TypeError("Stock quantity must be a non-boolean integer.")

        # Enforce a non-negative stock invariant on initial creation.
        if quantity < 0:
            raise ValueError("Stock quantity cannot be negative.")

        # Reject non-string status values.
        if not isinstance(status, str):
            raise TypeError("Status must be a string.")

        # Normalize status casing before checking allowed lifecycle values.
        normalized_status: str = status.strip().casefold()

        # Reject unsupported lifecycle states.
        if normalized_status not in self.VALID_STATUSES:
            raise ValueError(f"Unsupported item status: {status}.")

        # Bind validated state onto the instance.
        self.sku_code: str = normalized_sku
        self.item_name: str = normalized_name
        self.stock_quantity: int = quantity
        self.status: str = normalized_status

if __name__ == "__main__":
    # Create a valid warehouse item instance.
    notebook: InventoryItem = InventoryItem(" sku-104 ", "  Spiral   Notebook ", 25, "ACTIVE")

    # Print normalized attributes from the constructed object.
    print(notebook.sku_code, notebook.item_name, notebook.stock_quantity, notebook.status)

3.2 __init__ vs. Factory Classmethods

Keep __init__ focused on receiving already-parsed, validated arguments, and use @classmethod factory constructors (such as from_record_string) when parsing external text or raw records. Calling cls(...) inside the classmethod ensures subclasses and invariants are respected automatically.

from __future__ import annotations

class WarehouseRecord:
    """Demonstrate classmethod factories alongside standard __init__ construction."""

    def __init__(self, code: str, unit_count: int) -> None:
        """Initialize a warehouse record with validated fields."""
        # Reject non-string product codes.
        if not isinstance(code, str):
            raise TypeError("Product code must be a string.")

        # Trim and uppercase the product code.
        cleaned_code: str = code.strip().upper()

        # Ensure product code is not empty.
        if not cleaned_code:
            raise ValueError("Product code cannot be blank.")

        # Guard against booleans masquerading as integers.
        if isinstance(unit_count, bool) or not isinstance(unit_count, int):
            raise TypeError("Unit count must be a non-boolean integer.")

        # Reject negative unit counts.
        if unit_count < 0:
            raise ValueError("Unit count cannot be negative.")

        # Assign validated attributes.
        self.product_code: str = cleaned_code
        self.unit_count: int = unit_count

    @classmethod
    def from_pipe_record(cls, record_line: str) -> "WarehouseRecord":
        """Parse a 'CODE | COUNT' string into a validated WarehouseRecord instance."""
        # Validate that the input record is a string.
        if not isinstance(record_line, str):
            raise TypeError("Record line must be a string.")

        # Partition around the first pipe delimiter.
        code, separator, count = record_line.partition("|")

        # Require both a delimiter and a non-empty count segment.
        if not separator or not count.strip():
            raise ValueError("Record must follow 'CODE | COUNT' format.")

        # Parse the count portion into an integer.
        try:
            count: int = int(count.strip())
        except ValueError as parse_error:
            raise ValueError(f"Invalid unit count in record: {record_line}.") from parse_error

        # Delegate to cls(...) so __init__ enforces all invariants.
        return cls(code=code, unit_count=count)


# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Build an instance from a delimited text record.
    record: WarehouseRecord = WarehouseRecord.from_pipe_record(" bk-77 | 12 ")

    # Display the parsed record fields.
    print(record.product_code, record.unit_count)

3.3 Object Identity (is) vs. Value Equality (==)

Two separate instances can hold identical field values while remaining distinct objects in memory. Defining __eq__ lets == compare domain identity or state cleanly, while is still tests whether two variables refer to the exact same instance.

class BadgeTag:
    """Compare object identity with 'is' and value equality with '=='."""

    def __init__(self, label: str) -> None:
        """Initialize a badge tag with a non-empty normalized label."""
        # Reject non-string label values.
        if not isinstance(label, str):
            raise TypeError("Label text must be a string.")

        # Normalize whitespace around the label.
        cleaned_label: str = " ".join(label.strip().split())

        # Reject empty labels.
        if not cleaned_label:
            raise ValueError("Label text cannot be blank.")

        # Store the normalized label.
        self.label: str = cleaned_label

    def __eq__(self, against: object) -> bool:
        """Return True when comparing another BadgeTag with the same label."""
        # Return NotImplemented so Python can handle reverse or non-matching comparisons cleanly.
        if not isinstance(against, BadgeTag):
            return NotImplemented

        # Compare normalized label text for value equality.
        return self.label == against.label

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Create two separate BadgeTag instances with matching content.
    primary_badge: BadgeTag = BadgeTag("Python")
    trimmed_badge: BadgeTag = BadgeTag("  Python  ")
    shared_badge_reference: BadgeTag = primary_badge

    # Check value equality (True) and object identity (False for separate instances, True for alias).
    print("Equal values (==):", primary_badge == trimmed_badge)
    print("Same object (is) separate:", primary_badge is trimmed_badge)
    print("Same object (is) alias:", primary_badge is shared_badge_reference)

3.4 State Transitions and Lifecycle Methods

Rather than letting callers mutate status flags or quantities into contradictory states, expose clear methods that check current state and enforce valid transitions. Properties (@property, setters, and deleters) are used below to guard attribute access and will be covered in detail in Chapter 6.

from enum import Enum
from typing import Union

class ShipmentStatus(str, Enum):
    """Allowed lifecycle states for an order shipment."""

    PENDING = "pending"
    DISPATCHED = "dispatched"
    CANCELLED = "cancelled"

class OrderShipment:
    """Manage shipment state transitions while protecting quantity and status invariants."""

    def __init__(self, shipment_id: str, number_of_items: int) -> None:
        """Initialize a pending shipment with a validated identifier and item count."""
        # Initialize backing attributes before assigning through properties.
        self._shipment_id: str = ""
        self._number_of_items: int = 0
        self._status: ShipmentStatus = ShipmentStatus.PENDING

        # Assign through property setters so all invariants run in one place.
        self.id = shipment_id
        self.number_of_items = number_of_items
        self.status = ShipmentStatus.PENDING

    @property
    def id(self) -> str:
        """Return the normalized shipment identifier."""
        # Guard against uninitialized or blank identifier state.
        if not hasattr(self, "_shipment_id") or not self._shipment_id:
            raise AttributeError("Shipment identifier is not initialized.")

        return self._shipment_id

    @id.setter
    def id(self, identifier: str) -> None:
        """Validate and set the normalized shipment identifier while pending."""
        # Reject non-string identifiers defensively.
        if not isinstance(identifier, str):
            raise TypeError("Shipment ID must be a string.")

        # Prevent changing the shipment ID once dispatched or cancelled.
        if hasattr(self, "_status") and self._status is not ShipmentStatus.PENDING:
            raise ValueError(
                f"Cannot modify shipment ID when status is '{self._status.value}'."
            )

        # Normalize whitespace and casing for consistent lookups.
        normalized_identifier: str = identifier.strip().upper()

        # Require a non-empty identifier after normalization.
        if not normalized_identifier:
            raise ValueError("Shipment ID cannot be blank.")

        self._shipment_id = normalized_identifier

    @id.deleter
    def id(self) -> None:
        """Prevent accidental deletion of an active shipment identifier."""
        # Protect shipment traceability by disallowing identifier deletion.
        raise RuntimeError("Shipment ID cannot be deleted once created.")

    @property
    def number_of_items(self) -> int:
        """Return the validated number of items in the shipment."""
        # Guard against missing or uninitialized item count state.
        if not hasattr(self, "_number_of_items") or self._number_of_items is None:
            raise AttributeError("Item count has been cleared or is uninitialized.")

        return self._number_of_items

    @number_of_items.setter
    def number_of_items(self, number_of_items: int) -> None:
        """Validate and set a positive non-boolean item count while pending."""
        # Prevent item quantity changes after dispatch or cancellation.
        if hasattr(self, "_status") and self._status is not ShipmentStatus.PENDING:
            raise ValueError(
                f"Cannot update item count when status is '{self._status.value}'."
            )

        # Reject booleans explicitly because bool subclasses int in Python.
        if isinstance(number_of_items, bool) or not isinstance(number_of_items, int):
            raise TypeError("Item count must be a non-boolean integer.")

        # Enforce a strictly positive quantity invariant.
        if number_of_items <= 0:
            raise ValueError("Item count must be greater than zero.")

        self._number_of_items = number_of_items

    @number_of_items.deleter
    def number_of_items(self) -> None:
        """Clear the item count only if the shipment is cancelled."""
        # Allow clearing item count only when the shipment has been cancelled.
        if self._status is not ShipmentStatus.CANCELLED:
            raise ValueError(
                f"Cannot delete item count while status is '{self._status.value}'."
            )

        # Reset item count to zero rather than leaving a dangling attribute.
        self._number_of_items = 0

    @property
    def status(self) -> ShipmentStatus:
        """Return the current shipment lifecycle status."""
        # Guard against uninitialized or deleted status state.
        if not hasattr(self, "_status") or self._status is None:
            raise AttributeError("Shipment status is not initialized.")

        return self._status

    @status.setter
    def status(self, status: Union[ShipmentStatus, str]) -> None:
        """Validate and transition shipment status according to allowed rules."""
        # Convert valid status strings into ShipmentStatus enum members.
        if isinstance(status, str) and not isinstance(status, ShipmentStatus):
            try:
                resolved_status: ShipmentStatus = ShipmentStatus(status.strip().lower())
            except ValueError as exc:
                raise ValueError(f"Invalid shipment status '{status}'.") from exc
        elif isinstance(status, ShipmentStatus):
            resolved_status = status
        else:
            raise TypeError("Shipment status must be a ShipmentStatus or valid status string.")

        # Allow idempotent assignment if the shipment already has the target status.
        if hasattr(self, "_status") and self._status is resolved_status:
            return

        # Enforce allowed transitions from PENDING to DISPATCHED or CANCELLED.
        if hasattr(self, "_status"):
            if self._status is not ShipmentStatus.PENDING:
                raise ValueError(
                    f"Cannot transition status from '{self._status.value}' "
                    f"to '{resolved_status.value}'."
                )

            if resolved_status not in (ShipmentStatus.DISPATCHED, ShipmentStatus.CANCELLED):
                raise ValueError(
                    f"Unsupported transition from pending to '{resolved_status.value}'."
                )

        self._status = resolved_status

    @status.deleter
    def status(self) -> None:
        """Reset a cancelled shipment back to pending if needed."""
        # Only cancelled shipments can be reopened to pending via deleter.
        if self._status is not ShipmentStatus.CANCELLED:
            raise ValueError(
                f"Cannot reset status when shipment is '{self._status.value}'."
            )

        # Restore shipment to pending state.
        self._status = ShipmentStatus.PENDING

    def dispatch(self) -> None:
        """Transition a pending shipment to dispatched."""
        # Delegate transition validation to the status property setter.
        self.status = ShipmentStatus.DISPATCHED

    def cancel(self) -> None:
        """Transition a pending shipment to cancelled."""
        # Delegate transition validation to the status property setter.
        self.status = ShipmentStatus.CANCELLED


# Execute demonstration workflow only when running this module directly.
if __name__ == "__main__":
    # Create a shipment and update quantity while still pending.
    shipment: OrderShipment = OrderShipment("shp-900", 4)
    shipment.number_of_items = 6

    # Dispatch the shipment and print its public properties.
    shipment.dispatch()

    print(
        shipment.id,
        shipment.number_of_items,
        shipment.status.value,
    )

    # Demonstrate deleting item count on a cancelled shipment.
    cancelled_shipment: OrderShipment = OrderShipment("shp-901", 2)
    cancelled_shipment.cancel()

    del cancelled_shipment.number_of_items

    print(
        cancelled_shipment.id,
        cancelled_shipment.number_of_items,
        cancelled_shipment.status.value,
    )
