Chapter 1: Setting Up Python

Before writing useful Python programs, you need a clean, dependable development environment where you can test ideas quickly, organize scripts, and run code from the command line.

1.1 Installing Python Across Platforms

Python runs on Windows, macOS, and Linux. Download the latest stable release of Python 3 from python.org or use your system's package manager.

Windows: Official Installer & PATH Setup

Installing Python on Windows is straightforward as long as you add it to your system PATH:

  1. Visit python.org/downloads and download the latest Python 3 installer.
  2. Run the installer and check Add python.exe to PATH at the bottom of the first screen.
  3. Click Install Now and wait for the setup to finish.
  4. Open Command Prompt or PowerShell and verify your installation:
    python --version
macOS: Homebrew or Official Installer

macOS includes older system tools, so installing a current Python 3 build gives you modern features and clean package management:

  1. Open the Terminal app from Applications > Utilities.
  2. Install Python via Homebrew (recommended) or download the macOS installer from python.org:
    brew install python
  3. Verify the installed version in your terminal:
    python3 --version
Linux: System Package Manager

Most Linux distributions include Python 3 or provide it through their package manager:

  • Ubuntu / Debian / Linux Mint:
    sudo apt update && sudo apt install python3 python3-pip python3-venv
  • Fedora / RHEL:
    sudo dnf install python3 python3-pip
  • Arch Linux / Manjaro:
    sudo pacman -S python python-pip

Verify your installation in the terminal:
python3 --version

Install the PyCharm IDE

Download and install the PyCharm IDE from jetbrains.com/pycharm/download so you have smart refactoring, type inspection, virtual environment support, and a built-in debugger ready for multi-module Python code:

  1. Go to jetbrains.com/pycharm/download and download the installer for your operating system.
  2. Run the installer and open your project workspace folder in PyCharm.
  3. Point PyCharm's project interpreter to your Python 3 installation or virtual environment.

1.2 Exploring the Interactive Shell (REPL)

Python includes an interactive shell often called a REPL (Read–Evaluate–Print Loop). To open it, launch your terminal or command prompt and run python (or python3 on macOS/Linux) with no script filename after it. When the >>> prompt appears, you can type expressions one line at a time and see the result immediately.

# 1. Open your terminal or command prompt and launch the REPL
python
# Or on systems where Python 3 uses python3:
python3
>>> 15 + 27
42
>>> "Python " + "in Practice"
'Python in Practice'
>>> exit()

Tip: You can also exit the REPL by pressing Ctrl + Z then Enter on Windows, or Ctrl + D on macOS and Linux. When you want to save multi-line programs, exit the REPL and create a .py file in your code editor instead.

1.3 Writing and Running Your First Script

Create a project folder for your book exercises, add a file named greet_reader.py, and write a clean entry point with basic input validation.

def greet_reader(reader_name: str) -> str:
    """Return a clean greeting message for a non-empty reader name."""
    # Validate that the provided reader name is a string instance.
    if not isinstance(reader_name, str):
        raise TypeError("Reader name must be a valid string.")

    # Strip leading and trailing whitespace so blank spaces count as empty.
    sanitized_reader_name: str = reader_name.strip()

    # Reject empty strings after trimming whitespace.
    if not sanitized_reader_name:
        raise ValueError("Reader name cannot be empty.")

    return f"Welcome to Python in Practice, {sanitized_reader_name}!"


def main() -> None:
    """Run the reader greeting workflow with error and cleanup handling."""
    readers_fullname: str = "Braiden, Gole"
    greeting: str = ""

    try:
        # Attempt to build the welcome message from the configured reader name.
        greeting = greet_reader(readers_fullname)
    except (TypeError, ValueError) as exception:
        # Report validation failures without crashing the program driver.
        print(f"Configuration error: {exception}")
    finally:
        # Ensure final status logging runs whether greeting succeeded or failed.
        print(greeting)

# Run the entry point only when this module is executed directly.
if __name__ == "__main__":
    main()

Save greet_reader.py, open your terminal in that folder, and run your script:

# Run on Windows, macOS, or Linux
python greet_reader.py
# Or on systems where Python 3 is mapped to python3:
python3 greet_reader.py

Why if __name__ == "__main__": matters: It ensures main() runs when you execute the file directly, while letting other scripts import greet_reader() later without running top-level code automatically.

1.4 Checklist

Before moving on to variables and data types in Chapter 2, make sure each item below works on your machine:

  • Python Accessible in Terminal: Running python --version or python3 --version prints a Python 3 version number.
  • PyCharm IDE Ready: You downloaded PyCharm from jetbrains.com/pycharm/download and opened your workspace folder.
  • REPL Tested: You opened the interactive shell, evaluated an expression, and exited cleanly.
  • First Script Executed: You created greet_reader.py and ran it from the command line without errors.
