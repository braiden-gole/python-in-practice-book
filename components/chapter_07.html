Chapter 7: Context Manager Classes & Resource Lifecycles

Many real-world operations acquire a resource, perform work inside a scoped block, and must release or roll back that resource even when an exception occurs. Writing context manager classes with __enter__ and __exit__ makes setup, teardown, and error handling deterministic and readable.

Why context manager classes shine: When a resource has state—such as an active transaction, a temporary workspace, or an acquired lock, a class-based context manager can hold lifecycle state cleanly and guarantee cleanup on every exit path.

Understanding __exit__ return values: Returning False (or None) from __exit__ lets any exception raised inside the with block propagate after cleanup finishes; returning True suppresses the exception intentionally.

Lifecycle Hook Signature / Behavior Primary Role Defensive Pitfall to Avoid
Context Entry def __enter__(self) -> TargetType: Acquires or activates the resource and returns the object bound by as Leaving half-initialized resources if setup fails partway through
Context Exit def __exit__(self, exc_type, exc_val, exc_tb) -> bool: Releases resources, commits/rolls back state, and decides exception propagation Swallowing exceptions accidentally by returning True without a clear rule
Resource State Active flag / status guard Prevents using a closed or finalized resource outside its active scope Allowing writes or commits after the with block has already exited
Idempotent Teardown Guard against repeated cleanup Ensures closing or releasing twice never raises secondary errors Raising an AttributeError when cleaning up after a failed __enter__
Core Principles of Context Manager Lifecycles
  • Always clean up before deciding exception suppression: Release locks, buffers, or temporary handles in __exit__ whether exc_type is None or an exception occurred.
  • Default to propagating unexpected errors: Return False from __exit__ unless your domain explicitly handles and suppresses a specific exception type.
  • Guard operations against inactive sessions: Check that the context is currently active before allowing mutations or commits inside the block.
  • Keep cleanup idempotent: Make teardown safe to run once even if partial initialization occurred during __enter__.

7.1 Scoped Transaction Rollback and Commit

A transactional context manager lets callers stage changes inside a with block, automatically commits when the block finishes cleanly, and rolls back staged changes if an error occurs.

from types import TracebackType
from typing import Optional, Type

class StagingLedgerSession:
    """Context manager staging balance adjustments and rolling back on failure."""

    def __init__(self, initial_credit: int) -> None:
        """Initialize a session with a validated non-negative credit balance."""
        # Reject booleans explicitly because bool subclasses int in Python.
        if isinstance(initial_credit, bool) or not isinstance(initial_credit, int):
            raise TypeError("Initial credit must be a non-boolean integer.")

        # Enforce a non-negative starting credit balance.
        if initial_credit < 0:
            raise ValueError("Initial credit cannot be negative.")

        # Store committed balance, working draft balance, and active status.
        self._committed_credit: int = initial_credit
        self._draft_credit: int = initial_credit
        self._session_active: bool = False

    @property
    def committed_credit(self) -> int:
        """Return the finalized credit balance."""
        # Return the committed credit amount.
        return self._committed_credit

    def apply_adjustment(self, credit_delta: int) -> None:
        """Apply a signed integer adjustment within an active session."""
        # Ensure the caller is inside an active 'with' block.
        if not self._session_active:
            raise RuntimeError("Cannot adjust credit outside an active session.")

        # Reject booleans explicitly because bool subclasses int in Python.
        if isinstance(credit_delta, bool) or not isinstance(credit_delta, int):
            raise TypeError("Credit delta must be a non-boolean integer.")

        # Compute candidate balance and prevent negative draft credit.
        proposed_credit: int = self._draft_credit + credit_delta

        if proposed_credit < 0:
            raise ValueError("Draft credit cannot drop below zero.")

        # Stage the validated adjustment in the draft balance.
        self._draft_credit = proposed_credit

    def __enter__(self) -> "StagingLedgerSession":
        """Activate the session and reset draft state to committed balance."""
        # Prevent nested re-entry on the same active session instance.
        if self._session_active:
            raise RuntimeError("StagingLedgerSession is already active.")

        # Start from the last committed balance and mark session active.
        self._draft_credit = self._committed_credit
        self._session_active = True

        return self

    def __exit__(self,
        exception_type: Optional[Type[BaseException]],
        exception_value: Optional[BaseException],
        traceback_obj: Optional[TracebackType],
    ) -> bool:
        """Commit staged credit on success or roll back to committed credit on error."""
        # Commit changes when exiting cleanly without an exception.
        if exception_type is None:
            self._committed_credit = self._draft_credit
        else:
            # Discard staged changes when an exception unwinds the block.
            self._draft_credit = self._committed_credit

        # Mark the session closed and allow any exception to propagate.
        self._session_active = False

        return False

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Commit a valid adjustment inside a 'with' block.
    ledger_session: StagingLedgerSession = StagingLedgerSession(initial_credit=100)

    with ledger_session as active_session:
        active_session.apply_adjustment(25)
        active_session.apply_adjustment(-10)

    print("After commit:", ledger_session.committed_credit)

    # Demonstrate automatic rollback when an error happens mid-block.
    try:
        with ledger_session as active_session:
            active_session.apply_adjustment(50)
            active_session.apply_adjustment(-500)
    except ValueError as validation_error:
        print("Rolled back after error:", validation_error)

    print("After rollback:", ledger_session.committed_credit)

7.2 Guarded Execution Timer and Diagnostic Capture

Context managers are also useful for measuring elapsed execution time or recording operation outcomes without scattering timing and teardown logic across every call site.

from time import perf_counter
from types import TracebackType
from typing import Optional, Type

class OperationStopwatch:
    """Context manager recording elapsed duration and completion status of a block."""

    def __init__(self, operation_label: str) -> None:
        """Initialize a stopwatch with a validated non-empty label."""
        # Reject non-string operation labels defensively.
        if not isinstance(operation_label, str):
            raise TypeError("Operation label must be a string.")

        # Normalize whitespace and require a non-empty label.
        cleaned_label: str = " ".join(operation_label.strip().split())

        if not cleaned_label:
            raise ValueError("Operation label cannot be blank.")

        # Initialize timing and status fields before entering the block.
        self._operation_label: str = cleaned_label
        self._start_timestamp: Optional[float] = None
        self._elapsed_seconds: Optional[float] = None
        self._succeeded: Optional[bool] = None

    @property
    def elapsed_seconds(self) -> Optional[float]:
        """Return elapsed seconds once the block completes, or None while running."""
        # Expose elapsed runtime as a read-only property.
        return self._elapsed_seconds

    @property
    def succeeded(self) -> Optional[bool]:
        """Return True if the block finished without error, False if failed, or None."""
        # Expose completion status as a read-only property.
        return self._succeeded

    def __enter__(self) -> "OperationStopwatch":
        """Start high-resolution timing when entering the context."""
        # Reset prior measurements and record start timestamp.
        self._elapsed_seconds = None
        self._succeeded = None
        self._start_timestamp = perf_counter()

        return self

    def __exit__(
        self,
        exception_type: Optional[Type[BaseException]],
        exception_value: Optional[BaseException],
        traceback_obj: Optional[TracebackType],
    ) -> bool:
        """Record elapsed time and outcome status when exiting the context."""
        # Compute elapsed duration if a start timestamp was recorded.
        if self._start_timestamp is not None:
            self._elapsed_seconds = perf_counter() - self._start_timestamp
            self._start_timestamp = None

        # Record whether the block completed without raising an exception.
        self._succeeded = exception_type is None
        
        return False

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Measure a short computation block and inspect recorded metrics.
    timer: OperationStopwatch = OperationStopwatch("  batch normalization ")
    with timer as active_timer:
        total_sum: int = sum(range(10000))

    print("Sum:", total_sum)
    print("Succeeded:", timer.succeeded)
    print("Elapsed recorded:", timer.elapsed_seconds is not None)
