Chapter 5: Dunder Protocols, Operator Overloading & Custom Containers

Python integrates custom classes with built-in syntax such as len(), in, indexing, iteration, and arithmetic operators through dunder (double-underscore) protocols. Implementing these hooks thoughtfully makes domain objects feel native while preserving strict invariants.

What makes a protocol work well: Dunder methods should follow standard Python expectations rather than surprising callers. For example, + should return a new object rather than mutating an operand, and unsupported types should return NotImplemented so Python can try the reflected method or raise a clear TypeError.

Custom containers vs. raw lists: Wrapping internal collections inside a custom container lets you enforce element types, support slicing or key lookups cleanly, and expose only valid container behaviors. (Reusable attribute descriptors and property lifecycle rules are covered separately in Chapter 6.)

Protocol Area Key Dunder Methods Expected Behavior Defensive Pitfall to Avoid
Representation __repr__, __str__ __repr__ aids debugging/logging; __str__ formats human-friendly text Raising exceptions or relying on uninitialized fields inside string formatting
Operator Overloading __add__, __radd__, __mul__, __rmul__ Returns a new instance; returns NotImplemented for incompatible operand types Silently mixing incompatible currencies or allowing bool as a numeric multiplier
Sequence & Container __len__, __getitem__, __contains__, __iter__ Supports len(box), indexing/slicing, item in box, and for item in box Returning raw internal mutable lists that callers can alter outside validation
Truthiness __bool__, __len__ Evaluates whether an object is non-empty or active in if obj: checks Defining conflicting truthiness rules that surprise callers expecting emptiness checks
Core Principles of Protocols & Containers
  • Return NotImplemented for unknown operands: Returning NotImplemented from binary operators tells Python to test the right-hand operand's reflected method (such as __rmul__) before raising TypeError.
  • Keep __add__ pure and __len__ non-negative: Arithmetic operators should produce new objects rather than mutating inputs, and __len__ must return a non-negative int.
  • Handle both integer indices and slice objects: When implementing __getitem__, check isinstance(index_or_slice, slice) so slicing works alongside single-item lookup.
  • Guard internal collection state: Validate every element added to a custom container so invalid items never enter the collection.

5.1 Operator Overloading and Reflected Operations

Overloading arithmetic operators like + and * makes value-like objects ergonomic in expressions. Implementing both normal and reflected methods (such as __mul__ and __rmul__) lets callers write either price * 3 or 3 * price.

from __future__ import annotations

from decimal import Decimal, InvalidOperation, ROUND_HALF_UP
from typing import Union

class LedgerAmount:
    """Money value supporting addition and scalar multiplication with strict checks."""

    def __init__(self, amount_value: Union[Decimal, int, float, str], currency_code: str) -> None:
        """Initialize and validate a monetary amount and three-letter currency code."""
        # Reject booleans explicitly because bool subclasses int.
        if isinstance(amount_value, bool):
            raise TypeError("Amount cannot be a boolean.")

        # Convert supported input types into a Decimal.
        try:
            if isinstance(amount_value, Decimal):
                parsed_value: Decimal = amount_value
            elif isinstance(amount_value, (int, float, str)):
                parsed_value = Decimal(str(amount_value).strip())
            else:
                raise TypeError("Amount must be a Decimal, int, float, or str.")
        except InvalidOperation as parse_error:
            raise ValueError(f"Invalid amount value: {amount_value}.") from parse_error

        # Reject non-finite values like NaN or Infinity.
        if not parsed_value.is_finite():
            raise ValueError("Amount must be a finite number.")

        # Ensure currency code is a string.
        if not isinstance(currency_code, str):
            raise TypeError("Currency code must be a string.")

        # Trim and uppercase the currency code.
        normalized_currency: str = currency_code.strip().upper()

        # Require a three-letter alphabetic code.
        if len(normalized_currency) != 3 or not normalized_currency.isalpha():
            raise ValueError("Currency code must be a three-letter alphabetic code.")

        # Round to two decimals and store fields.
        self._amount: Decimal = parsed_value.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
        self._currency: str = normalized_currency

    @property
    def amount(self) -> Decimal:
        """Return the rounded monetary amount."""
        # Return the stored Decimal amount.
        return self._amount

    @property
    def currency(self) -> str:
        """Return the normalized currency code."""
        # Return the stored currency code.
        return self._currency

    def __repr__(self) -> str:
        """Return an unambiguous developer representation."""
        # Format constructor arguments for debugging.
        return f"LedgerAmount(amount_value={str(self._amount)!r}, currency_code={self._currency!r})"

    def __str__(self) -> str:
        """Return a readable display string for amounts."""
        # Format amount and currency for display.
        return f"{self._amount} {self._currency}"

    def __add__(self, operand: object) -> "LedgerAmount":
        """Add two LedgerAmount instances with matching currencies."""
        # Defer to Python if operand is not a LedgerAmount.
        if not isinstance(operand, LedgerAmount):
            return NotImplemented

        # Block addition across different currencies.
        if self._currency != operand._currency:
            raise ValueError(
                f"Cannot add currency '{operand._currency}' to '{self._currency}'."
            )

        # Return a new summed LedgerAmount.
        return LedgerAmount(self._amount + operand._amount, self._currency)

    def __mul__(self, multiplier: object) -> "LedgerAmount":
        """Multiply a LedgerAmount by a non-boolean integer or Decimal multiplier."""
        # Reject booleans because bool subclasses int.
        if isinstance(multiplier, bool):
            raise TypeError("Multiplier cannot be a boolean.")

        # Scale amount by a non-negative integer or finite Decimal.
        if isinstance(multiplier, int):
            if multiplier < 0:
                raise ValueError("Multiplier cannot be negative.")

            scaled_amount: Decimal = self._amount * Decimal(multiplier)
        elif isinstance(multiplier, Decimal):
            if not multiplier.is_finite():
                raise ValueError("Multiplier must be finite.")

            if multiplier < Decimal("0"):
                raise ValueError("Multiplier cannot be negative.")

            scaled_amount = self._amount * multiplier
        else:
            # Defer to reflected multiplication or TypeError.
            return NotImplemented

        # Return a new scaled LedgerAmount.
        return LedgerAmount(scaled_amount, self._currency)

    def __rmul__(self, multiplier: object) -> "LedgerAmount":
        """Support reversed scalar multiplication such as 3 * amount."""
        # Reuse __mul__ validation and scaling logic.
        return self.__mul__(multiplier)

if __name__ == "__main__":
    # Create an amount and test forward and reflected multiplication plus addition.
    unit_fee: LedgerAmount = LedgerAmount("12.50", "cad")

    triple_fee: LedgerAmount = unit_fee * 3
    double_from_left: LedgerAmount = 2 * unit_fee
    combined_total: LedgerAmount = triple_fee + double_from_left

    # Print formatted outputs.
    print(repr(unit_fee))
    print("Combined total:", str(combined_total))

5.2 Building a Custom Container with Sequence Protocols

A custom container encapsulates an internal collection so callers can use familiar idioms len(manifest), item in manifest, manifest[0], slicing, and for item in manifest while enforcing element rules at every entry point.

from typing import Iterator, Optional, Union

class PackageManifest:
    """Validated container storing normalized tracking codes for a shipment batch."""

    def __init__(self, tracking_codes: Optional[list[str]] = None) -> None:
        """Initialize an empty or pre-populated manifest of normalized tracking codes."""
        # Create a private list for stored codes.
        self._codes: list[str] = []

        # Validate and add any initial codes.
        if tracking_codes is not None:
            if not isinstance(tracking_codes, list):
                raise TypeError("Initial tracking_codes must be a list of strings.")

            for raw_code in tracking_codes:
                self.append_code(raw_code)

    @staticmethod
    def _normalize_code(raw_code: object) -> str:
        """Validate and normalize a single tracking code string."""
        # Reject non-string codes.
        if not isinstance(raw_code, str):
            raise TypeError("Tracking code must be a string.")

        # Trim and uppercase the code.
        cleaned_code: str = raw_code.strip().upper()

        # Reject blank codes.
        if not cleaned_code:
            raise ValueError("Tracking code cannot be blank.")

        # Return normalized code.
        return cleaned_code

    def append_code(self, raw_code: str) -> None:
        """Validate and append a normalized tracking code to the manifest."""
        # Normalize and append the code.
        normalized_code: str = self._normalize_code(raw_code)

        self._codes.append(normalized_code)

    def __len__(self) -> int:
        """Return the number of tracking codes in the manifest."""
        # Return stored code count.
        return len(self._codes)

    def __bool__(self) -> bool:
        """Return True when the manifest contains at least one tracking code."""
        # Check if any codes are stored.
        return len(self._codes) > 0

    def __contains__(self, candidate: object) -> bool:
        """Support 'in' membership checks using normalized code matching."""
        # Reject non-string lookup targets.
        if not isinstance(candidate, str):
            return False

        # Normalize target and check membership.
        normalized_target: str = candidate.strip().upper()

        return normalized_target in self._codes

    def __getitem__(self, index_or_slice: Union[int, slice]) -> Union[str, list[str]]:
        """Support integer indexing and slice access over stored tracking codes."""
        # Return a new list copy for slices.
        if isinstance(index_or_slice, slice):
            return list(self._codes[index_or_slice])

        # Reject booleans and non-integer indices.
        if isinstance(index_or_slice, bool) or not isinstance(index_or_slice, int):
            raise TypeError("Index must be an integer or slice.")

        # Return item at index.
        return self._codes[index_or_slice]

    def __iter__(self) -> Iterator[str]:
        """Yield tracking codes in insertion order."""
        # Yield an iterator over stored codes.
        return iter(self._codes)

    def __repr__(self) -> str:
        """Return a clear representation of the manifest."""
        # Format manifest state for debugging.
        return f"PackageManifest(tracking_codes={self._codes!r})"

if __name__ == "__main__":
    # Create a manifest, append a code, and test container protocols.
    manifest: PackageManifest = PackageManifest([" trk-101 ", "trk-102"])

    manifest.append_code(" trk-103 ")

    # Verify length, truthiness, membership, indexing, and iteration.
    print("Count:", len(manifest))
    print("Non-empty:", bool(manifest))
    print("Has TRK-102:", " trk-102 " in manifest)
    print("First item:", manifest[0])
    print("Slice [1:]:", manifest[1:])

    for entry in manifest:
        print("Entry:", entry)

5.3 Custom Mapping-Style Container with Key Normalization

For dictionary-like collections, implementing __getitem__, __setitem__, __delitem__, __contains__, and __len__ lets you normalize keys consistently while keeping value invariants intact.

from typing import Iterator

class CaseInsensitiveQuotaStore:
    """Mapping-style container with normalized uppercase keys and non-negative counts."""

    def __init__(self) -> None:
        """Initialize an empty internal dictionary for quota entries."""
        # Initialize private quota mapping.
        self._quotas: dict[str, int] = {}

    @staticmethod
    def _normalize_key(raw_key: object) -> str:
        """Validate and normalize a quota key into an uppercase string."""
        # Reject non-string keys.
        if not isinstance(raw_key, str):
            raise TypeError("Quota key must be a string.")

        # Trim and uppercase the key.
        cleaned_key: str = raw_key.strip().upper()

        # Reject blank keys.
        if not cleaned_key:
            raise ValueError("Quota key cannot be blank.")

        # Return normalized key.
        return cleaned_key

    @staticmethod
    def _validate_quota(raw_quota: object) -> int:
        """Validate that quota value is a non-negative non-boolean integer."""
        # Reject booleans and non-integers.
        if isinstance(raw_quota, bool) or not isinstance(raw_quota, int):
            raise TypeError("Quota value must be a non-boolean integer.")

        # Reject negative quota values.
        if raw_quota < 0:
            raise ValueError("Quota value cannot be negative.")

        # Return validated quota.
        return raw_quota

    def __setitem__(self, raw_key: str, raw_quota: int) -> None:
        """Set or update a quota entry using a normalized key and validated count."""
        # Normalize key, validate quota, and store entry.
        normalized_key: str = self._normalize_key(raw_key)
        validated_quota: int = self._validate_quota(raw_quota)

        self._quotas[normalized_key] = validated_quota

    def __getitem__(self, raw_key: str) -> int:
        """Retrieve the quota count for a normalized key."""
        # Look up normalized key or raise KeyError.
        normalized_key: str = self._normalize_key(raw_key)

        if normalized_key not in self._quotas:
            raise KeyError(f"Unknown quota key: {normalized_key}.")

        # Return stored quota count.
        return self._quotas[normalized_key]

    def __delitem__(self, raw_key: str) -> None:
        """Delete an existing quota entry by normalized key."""
        # Remove normalized key or raise KeyError.
        normalized_key: str = self._normalize_key(raw_key)

        if normalized_key not in self._quotas:
            raise KeyError(f"Cannot delete missing quota key: {normalized_key}.")

        # Delete entry from mapping.
        del self._quotas[normalized_key]

    def __contains__(self, raw_key: object) -> bool:
        """Check whether a normalized key exists in the quota store."""
        # Reject non-string keys during lookup.
        if not isinstance(raw_key, str):
            return False

        # Trim and uppercase key for check.
        cleaned_key: str = raw_key.strip().upper()

        # Reject blank keys.
        if not cleaned_key:
            return False

        # Check key presence.
        return cleaned_key in self._quotas

    def __len__(self) -> int:
        """Return the number of stored quota entries."""
        # Return entry count.
        return len(self._quotas)

    def __iter__(self) -> Iterator[str]:
        """Iterate over normalized quota keys."""
        # Yield keys from internal mapping.
        return iter(self._quotas)

# Run this block only when executing the file directly rather than importing it.
if __name__ == "__main__":
    # Populate and query the custom quota store using mixed-case keys.
    store: CaseInsensitiveQuotaStore = CaseInsensitiveQuotaStore()

    store[" api_calls "] = 1000
    store["storage_gb"] = 50

    print("API calls:", store["API_CALLS"])
    print("Has storage_gb:", "  STORAGE_GB " in store)
    print("Total keys:", len(store))

    del store["api_calls"]
    
    print("Remaining keys:", list(store))
