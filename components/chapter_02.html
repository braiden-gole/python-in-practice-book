Chapter 2: Type Hints, Data Types, Variables, and Strings

Once your Python environment is ready, the next building block is storing and shaping information. In Python, almost everything you work with is an object, and variables act as named labels pointing to those objects in memory. Pairing variables with type hints and defensive validation makes your code clearer to read and much easier to maintain as programs grow.

What type hints are: Type hints are optional annotations such as variable: Type, parameter: Type, and -> ReturnType that describe the expected data types of your values, function arguments, and return values.

Modern syntax vs. typing: Python 3.10+ lets you write union types cleanly with | (like str | None or int | float) and collection hints directly with list[str] or dict[str, int]. Older codebases or specialized cases also use constructs imported from the typing module, as summarized below.

Why they are used: Teams and individual developers use type hints to make dynamic Python code explicit about data contracts without sacrificing Python's flexibility. Because Python does not enforce type hints at runtime on its own, developers pair them with static type checkers (such as mypy or pyright) and runtime checks like isinstance().

Using from __future__ import annotations: When placed as the very first statement at the top of a Python module, from __future__ import annotations tells Python to store type hints as strings instead of evaluating them immediately at import time. This lets you reference classes or types defined later in the file (forward references) and helps avoid runtime evaluation issues with newer or postponed type expressions.

Why Type Hints Are Useful
  • Self-documenting code: Reading a function signature immediately shows what inputs it expects and what type it returns without digging through the entire body.
  • Earlier bug detection: Static analysis tools catch mismatched types, accidental None access, and invalid arguments before you even run the program.
  • Better editor support: Code editors and IDEs use type hints to provide accurate autocomplete suggestions, method hints, and inline warnings.
  • Safer refactoring: Changing a data shape or return type highlights every caller that needs updating, reducing silent regressions in larger codebases.
Common Type Hint Examples

  • Dictionary: section_counts: dict[str, int] = {"basics": 4}
  • Function returning a value: def format_label(chapter_number: int) -> str: return f"Chapter {chapter_number}"
  • Function returning nothing: def log_chapter_status(chapter_number: int) -> None: print(chapter_number)

2.1 Variables and How Assignment Works

Unlike some lower-level languages where a variable is a fixed box of memory with a rigid size, a Python variable is a name bound to an object. When you assign a value with =, Python creates or locates the object first and then attaches the variable name to it.

Key Assignment Rules
  • Dynamic rebinding: The same variable name can later point to a different value or even a different type.
  • Descriptive naming: Use clear, descriptive snake_case names that explain what the value represents in your program rather than vague single letters.
  • Constants by convention: Names in UPPER_SNAKE_CASE signal values intended to stay fixed throughout execution.
def is_integer(value: object) -> bool:
    """Checks whether the value is and integer and not a boolean."""
    return not isinstance(value, bool) and isinstance(value, int)

def in_range(minimum: int, maximum: int, value: int) -> bool:
    """Determines if the index is within bounds."""
    if not all(is_integer(index) for index in (minimum, maximum, value)):
        raise TypeError("Minimum, maximum, and value mus all be integers.")
    
    # Reject inverted bounds so comparisons always make sense.
    if minimum > maximum:
        raise ValueError("Minimum bound cannot be greater than maximum.") 

    return minimum <= value <= maximum

def retrieve_number(prompt_message: str) -> int:
    """This is responsible for collecting a valid integer."""
    if not isinstance(prompt_message, str):
        raise TypeError("Prompt message must be a string.")

    return int(input(prompt_message))

def main() -> None:
    """Run the interactive loop that collects and validates a number."""
    cycle: bool = True

    within_reach: bool = False

    # Cycle until we receive a valid integer that is within range.
    while cycle: 
        try:
            # Keep cycling if we dont retrieve a number.
            number: int = retrieve_number("Enter in a number: ")

            # Keep cycling if we dont have a number in a valid range.
            within_reach = in_range(0, 100, number)

            cycle = False
        except (TypeError, ValueError):
            print("Please enter in a valid integer that is within bounds.")
    
    # Pythons Ternary statement.
    message: str = ("The number is within valid bounds." if within_reach else "The number is not in valid range.")

    # Feedback.
    print(message)

# Execute the entry point only when this file is run directly as a script.
if __name__ == "__main__":
    main()

2.2 Core Built-in Data Types

Every value in Python has a type that determines what operations are valid on it. You can inspect any object's type at runtime with type(value) or check it safely with isinstance(value, ExpectedType).

Data Type Type Hint Example Literal Typical Use Case
Integer int 42, -7, 1_000 Counts, indices, page numbers, loop limits
Float float 19.99, -0.5, 3.0 Prices, measurements, ratios, averages
String str "Python", 'Hello' Names, messages, file paths, user input
Boolean bool True, False Feature flags, validation results, conditions
NoneType None (in X | None) None Missing values, uninitialized or optional results

Important nuances: Booleans are a subclass of int (True == 1 and False == 0), so check isinstance(value, bool) before isinstance(value, int) when distinguishing them. Binary floats approximate decimal fractions (such as 0.1 + 0.2), so use round() for display or decimal.Decimal for exact financial values, and use None intentionally to represent missing or optional data. 

import math

from decimal import Decimal, InvalidOperation

def inventory_line(quantity: int, unit_price: str,
                   discount: float, is_featured: bool, aisle: str | None) -> str:
    """Validate inventory line inputs and return a formatted summary string."""
    # Check bool first because bool is a subclass of int in Python.
    if isinstance(quantity, bool) or not isinstance(quantity, int):
        raise TypeError("Quantity must be a non-boolean integer.")

    # Reject zero or negative quantities for active line items.
    if quantity <= 0:
        raise ValueError("Quantity must be a non-negative integer.")

    # Ensure unit price text is a non-empty string before Decimal conversion.
    if not isinstance(unit_price, str) or not unit_price.strip():
        raise TypeError("Unit price must be a non-empty string.")

    # Remove surrounding whitespace and any leading dollar sign from the price text.
    cleaned_price: str = unit_price.strip().removeprefix("$").strip()

    # Guard against strings that become empty after stripping currency symbols and spaces.
    if not cleaned_price:
        raise ValueError("Unit price must be a non-empty string.")

    try:
        # Use Decimal for exact base-10 currency math instead of binary float.
        exact_unit_price: Decimal = Decimal(cleaned_price)
    except InvalidOperation as exception:
        # Chain the decimal parsing failure onto a descriptive ValueError.
        raise ValueError(f"Invalid decimal string for unit price: {unit_price}.") from exception

    # Confirm the parsed price is finite and strictly positive.
    if not exact_unit_price.is_finite() or exact_unit_price <= Decimal("0"):
        raise ValueError("Unit price must be a finite positive decimal.")

    # Ensure discount is a plain number rather than a boolean or non-numeric type.
    if isinstance(discount, bool) or not isinstance(discount, (int, float)):
        raise TypeError("Discount rate must be a numeric value.")

    # Normalize the discount fraction to a standard float for range checking.
    normalized_discount: float = float(discount)

    # Verify the discount rate is finite and falls within the unit interval.
    if not math.isfinite(normalized_discount) or not (0.0 <= normalized_discount <= 1.0):
        raise ValueError("Discount rate must be a finite number between 0.0 and 1.0.")

    # Enforce an explicit boolean type for the featured flag.
    if not isinstance(is_featured, bool):
        raise TypeError("Featured item flag must be a boolean.")

    # Allow None or a string when validating the optional aisle identifier.
    if aisle is not None and not isinstance(aisle, str):
        raise TypeError("Aisle must be a non-empty string or None.")

    # Compute the unadjusted line subtotal from exact unit price and quantity.
    line_subtotal: Decimal = exact_unit_price * Decimal(quantity)

    # Convert the discount fraction into a rounded percentage value.
    discount_percent: float = round(float(discount) * 100.0, 1)

    # Select the display tag based on whether the item is featured.
    featured_badge: str = "[FEATURED]" if is_featured else "[STANDARD]"

    # Fall back to a default label when no non-blank aisle string is provided.
    aisle_label: str = aisle.strip() if aisle and aisle.strip() else "Unassigned"

    # Assemble and return the final single-line inventory summary string.
    return (
        f"{featured_badge} Quantity: {quantity} | "
        f"Subtotal: ${line_subtotal:.2f} | "
        f"Discount: {discount_percent:.2f} | "
        f"Aisle: {aisle_label}"
    )

# Run a sample execution when invoked directly as a script.
if __name__ == "__main__":
    # Demonstrate binary floating-point addition alongside rounding.
    binary_sum: float = 0.1 + 0.2
    rounded_sum: float = round(binary_sum, 2)

    # Build a sample inventory line using example arguments.
    summary: str = inventory_line(
        quantity=3,
        unit_price="$14.99",
        discount=0.15,
        is_featured=True,
        aisle="B-12"
    )

    # Output the formatted summary to standard output.
    print(summary)

2.3 Working with Strings

Strings (str) are ordered sequences of Unicode characters. In Python, strings are immutable, meaning once a string object is created, its characters cannot be modified in place methods like .strip(), .lower(), and .replace() return a new string instead.

Essential String Operations
  • Indexing and slicing: Access single characters with text[0] or text[-1] (from the end), and extract substrings with text[start:end:step] without raising an IndexError on out-of-range bounds.
  • Cleaning and normalization: Use .strip() to trim outer whitespace, .casefold() for case-insensitive comparisons, and .split() / .join() to break apart or assemble text.
  • f-strings (formatted string literals): Embed expressions directly inside {} braces, including format specifiers like :.2f for two decimal places.
def format_member_badge(display_name: str, membership_tier: str, discount_rate: float) -> str:
    """Clean raw string inputs and return a formatted membership badge."""
    # Guard against non-string display names.
    if not isinstance(display_name, str):
        raise TypeError("Display name must be a string.")

    # Guard against non-string membership tiers.
    if not isinstance(membership_tier, str):
        raise TypeError("Membership tier must be a string.")

    # Guard against invalid discount percentages.
    if isinstance(discount_rate, bool) or not isinstance(discount_rate, (int, float)):
        raise TypeError("Discount rate must be a number.")

    # Clamp or reject out-of-range discount rates.
    if discount_rate < 0.0 or discount_rate > 1.0:
        raise ValueError("Discount rate must be between 0.0 and 1.0.")

    # Trim outer whitespace and collapse repeated internal spaces in the display name.
    cleaned_display_name: str = " ".join(display_name.strip().split())

    # Normalized membership tier casing for consistent display.
    normalized_tier: str = membership_tier.strip().title()

    # Reject empty strings after trimming whitespace.
    if not cleaned_display_name:
        raise ValueError("Display name cannot be blank.")

    # Default empty tier labels to Standard.
    if not normalized_tier:
        normalized_tier = "Standard"

    # Collect uppercase first letters from each word token.
    initials: list[str] = []

    # Iterarte over split tokens to build the list of initials.
    for token in cleaned_display_name.split(" "):
        # Append the upppercase initial when the token is non-empty.
        if token:
            initials.append(token[0].upper())
        else:
            # Skip empty tokens caused by spacing.
            continue

    # Join collected initials or falll back to a question mark if empty.
    if initials:
        name_initials: str = "".join(initials)
    else:
        # Use a fallbach character when no initials are available.
        name_initials = "?"

    # Convert the discount fraction into a percentage value.
    discount_percent: float = float(discount_rate) * 100.0

    # Assemble and return the formatted subscriber badge string.
    return (
        f"({name_initials}) {cleaned_display_name} — "
        f"{normalized_tier} Member ({discount_percent:.0f}% off)"
    )

if __name__ == "__main__":
    # Format a sample subscriber badge with extra whitespace and lowercase tier.
    badge_text: str = format_member_badge("  avery   chen  ", "pro", 0.25)

    # Feedback.
    print(badge_text)

2.4 String Manipulation in Practice

Chaining string methods such as .split(), .strip(), .casefold(), .replace(), and .join() turns messy, uneven text into clean, consistent strings.

def clean_slugs(tag: str, delimiter: str = ",", number_of_slugs: int = 5, joiner: str = " | ") -> str:
    """Normalize messy delimited text into hyphenated lowercase slugs and join them."""
    # Reject non-string tag expressions before performing string operations.
    if not isinstance(tag, str):
        raise TypeError("Raw tag expression must be a string.")

    # Reject non-string or empty item delimiters.
    if not isinstance(delimiter, str) or not delimiter:
        raise ValueError("Item delimiter must be a non-empty string.")

    # Reject non-string or empty output joiners.
    if not isinstance(joiner, str) or not joiner:
        raise ValueError("Output joiner must be a non-empty string.")

    # Reject booleans and non-integer values for maximum slug count.
    if isinstance(number_of_slugs, bool) or not isinstance(number_of_slugs, int):
        raise TypeError("Maximum slug count must be an integer.")

    # Require a strictly positive slug limit.
    if number_of_slugs <= 0:
        raise ValueError("Maximum slug count must be greater than zero.")

    # Map unwanted punctuation characters to spaces so words stay separated cleanly.
    punctuation_table: dict[int, str] = str.maketrans(
        {
            "_": " ",
            "/": " ",
            "\\": " ",
            ":": " ",
            ";": " ",
            ".": " ",
            "!": " ",
            "?": " ",
            "#": "",
            "@": "",
        }
    )

    normalized_slug_list: list[str] = []
    seen_slug_keys: set[str] = set()

    # Split the raw expression by delimiter and transform each text segment.
    for segment in tag.split(delimiter):
        # Trim outer whitespace and remove optional leading or trailing brackets.
        trimmed_segment: str = (
            segment.strip()
            .removeprefix("[")
            .removesuffix("]")
            .strip()
        )

        # If a segment includes an assignment or colon label, keep the value after the separator.
        if "=" in trimmed_segment:
            _, _, trimmed_segment = trimmed_segment.partition("=")
            trimmed_segment = trimmed_segment.strip()

        # Translate punctuation into spacing or removal, then collapse repeated whitespace.
        translated_segment: str = trimmed_segment.translate(punctuation_table)
        collapsed_words: str = " ".join(translated_segment.split())

        # Case-fold for reliable Unicode comparisons and convert internal spaces to single hyphens.
        folded_text: str = collapsed_words.casefold()

        hyphenated_slug: str = "-".join(
            word_part for word_part in folded_text.split(" ") if word_part
        )

        # Collapse accidental consecutive hyphens and trim edge hyphens via slicing.
        while "--" in hyphenated_slug:
            hyphenated_slug = hyphenated_slug.replace("--", "-")

        if hyphenated_slug.startswith("-"):
            hyphenated_slug = hyphenated_slug[1:]

        if hyphenated_slug.endswith("-"):
            hyphenated_slug = hyphenated_slug[:-1]

        # Store non-empty unique slugs while preserving first-seen order.
        if hyphenated_slug and hyphenated_slug not in seen_slug_keys:
            seen_slug_keys.add(hyphenated_slug)
            normalized_slug_list.append(hyphenated_slug)

        # Stop processing once the requested slug cap is reached.
        if len(normalized_slug_list) >= number_of_slugs:
            break

    # Combine the resulting slug strings using the requested output joiner.
    return joiner.join(normalized_slug_list)


# Run a demonstration when executed directly as a script.
if __name__ == "__main__":
    # Transform noisy input text into clean, hyphenated slug segments.
    slug: str = clean_slugs(
        "  [topic = Python_3.12!!] ,  #Type__Hints  , python 3.12 ,  String   Methods//Slice  , ",
        delimiter=",",
        number_of_slugs=3,
        joiner=" | ",
    )

    # Print the resulting formatted string.
    print(slug)
